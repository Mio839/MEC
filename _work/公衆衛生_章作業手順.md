## 3. ⚠️ 1パート＝2問。2問書くたびに verify を回す

これが**この作業で最も重要な決まり**。理由は2つ。

1. 長い生成の後半は密度が落ちる。2問で切ると最後まで濃さが保てる。
2. **35問書いてから検証すると、落ちたときに全部作り直しになる**。2問なら直しも2問ぶん。

パート番号は `_ph_chNN_p1.py`, `p2.py`, … と連番。`_ph_join_chNN.py` が数字順に連結する。

## 4. 書き方（`Q()` の形）

**着手前に `_work/_ph_ch05_p1.py` の最初の `Q(...)` を丸ごと1件読むこと。** それが到達すべき水準の実物で、
以下はその骨格だけを抜いたもの。

```python
Q('120C-10',                      # 国試番号（spec の kid をそのまま。括弧は付けない）
  95,                             # 正答率（spec の rate。'－' なら None）
  [('bs', '★')],                 # バッジ。bs=★ bc=CBT bh=必修 bx=採点除外
                                  # ⚠️ bi(📷) は書かない＝imgs があれば Q() が自動で付ける
  '<strong>公費医療制度と根拠法の組合せで正しいのはどれか。</strong>',   # qt
  [('a', '結核患者の入院 ― 検疫法', False,
    '<span class="kw4">誤り。結核患者の入院医療費の公費負担は<u>感染症法</u>37条</span>による。'
    '<span class="kw4">検疫法は…（なぜ誤りかを機序・制度の筋で書く）</span>。'),
   ('b', '…', False, '…'),
   ('c', '…', True,  '<span class="kw3">◯ 正しい。…</span>'),
   ('d', '…', False, '…'),
   ('e', '…', False, '…')],
  '一言サマリ（.as に出る1〜2文）',
  # ⚠️ patho / deep / point は **(見出し, 本文) のタプル**。文字列を1つ渡すと壊れる。
  patho=('⚖️ 公費負担医療とは——「保険の外」を税が拾う仕組み',
         '<span class="kw3">…</span>…'),      # ep 病態／定義：機序で段階的に
  deep=('💡 …', '…'),                          # em 深掘り・覚え方・対比（ee 表の繰り返しにしない）
  point=('🎯 国試ポイント',                     # ept 番号つき複数項目＋関連知識へ横展開
         '<span class="kw">①…</span><br><span class="kw">②…</span><br>…'),
  ans_label=None)                 # 単一正解なら None でよい（正解肢の本文が自動で入る）
                                  # 複数正解も None でよい（'ａ・ｄ' が自動で入る）
                                  # 明示するのは採点除外（'（採点除外）'）と計算問題（'計算答：…'）だけ
```

- **選択肢は `(letter, text, ok, why)` の4つ組**。`why`（全肢の検討）を書けば `ee` 表は自動生成される。
- **正解肢の `why` は `<span class="kw3">◯ …</span>` で始める**。
- 強調は `kw`（重要）/ `kw3`（正解・肯定）/ `kw4`（誤り・注意）。**独自クラスを作らない**。
- 比較・鑑別は `<table class="tb">` で表にする。
- **カード番号はPDFの通し番号（NO.）**。章ごとに Q.1 へ振り直さない（`Q_START` が章頭NO.）。

## 5. 解説の中身 — 何を書き、何を書かないか

**レジュメPDF が解説の正本。** レジュメの記述と矛盾させない。

⚠️ **レジュメに無い数値・年号・法律の条番号を書かない。** どうしても必要なら
「制度としてこう位置づけられる」までに留め、**数字を出さない**。
公衆衛生は数値と定義の科目で、**もっともらしい嘘が最も混ざりやすい**。
とくに **第6章（介護保険）・第7章（人口）・第8章（疫学）**は危険。

⚠️ **レジュメと国試の事実が食い違ったら、どちらも書かない形で回避する。**
実例: レジュメは臨床研修を「努力義務」と書くが医師法16条の2 は義務。設問は義務の強さを
問うていないので「医師法に規定がある」までを書いて踏み込まなかった。同じ扱いをすること。

⚠️ **レジュメが薄い章でも水準は落とさない。** 第4章はレジュメが職種表1ページだけだったが、
**その表を骨格にして国試の出題論点で肉付け**し、第1〜3章を上回る厚みになった。

- **既存科目と重複する章が3つ**——ch15感染症↔`kansen`、ch16産業衛生・ch17環境問題↔`tox`。
  **重複問題は消さない**。ただし解説が既存科目と食い違わないようにする。
- **同一論点・ほぼ同一問題の組**が章内に繰り返し出る。消さず、
  「セットで確実に取る問題」として解説で明示する。
- **連問**は共通ステムを定数（`_STEM_NNN`）にして組の全カードの qt へ連結する。
  その設問だけの追加情報（既往歴・検査所見など）は定数に入れない。

## 6. 品質の下限（下回ると `verify_ph_ch.py` が **ERROR** で落ちる）

**章平均ではなく1問ずつ**見る。1問でも下回れば赤になる。

| 項目 | 下限 | 備考 |
|---|---|---|
| 解説ブロック | `ep → ee → em → ept` の**4枚・この順で完全一致** | 155問すべてがこの形 |
| 解説文字数 | **800字**（タグを除く） | 既存の実測最小863字・第5章平均1914字 |
| kw強調 | **25個** | 既存の実測最小31個・第5章平均54個 |
| ee の行数 | **選択肢数+1 以上** | 全肢を1つずつ検討したかを見る |

**目標は下限ではない。** 到達すべきは第5章の水準（**1問あたり 1914字 / kw 54個**）。
下限は「これを割ったら作り直し」の線であって、狙う値ではない。
参照する実物: `ph_ch05_q137`（1625字＝第5章の最薄）〜 `ph_ch05_q136`。

## 7. 事故ポイント（この科目で実際に踏んだもの）

1. **選択肢が表・図の問題** — 公衆衛生は2×2表・人口ピラミッド・統計グラフが多い。
   **テキスト抽出を信用しない。ページを300dpiで描画して目視で読む**
   （読めなければ600dpiへ。それでも駄目ならユーザーにスクリーンショットを依頼）。

   ```python
   import fitz
   fitz.open('MEC問題文pdf/MEC公衆衛生講座_問題（表紙2026）.pdf')[PDFページ-1] \
       .get_pixmap(dpi=300).save('p142.png')
   ```

   書き起こしは**列見出しを各肢に埋め込む形**（`ｃ　男児 50％／女児 50％`）。
   表を別に置いて肢を「a　①」にする方式は**採らない**（試験モードが肢をシャッフルして対応が崩れる）。
   ⚠️ **読んだら必ず解答表（spec）の正解と突き合わせる。** 列の対応を取り違えると
   静かに誤採点になる（`verify_ph_ch.py` の ans_label 検査がこれを捕まえる）。
2. **5択決め打ちのコードを書かない。** a〜f の6択・a〜g の7択・a〜i の9択が実在する
   （第5章では出なかったが第8章以降で出る）。`FW` は g まで持たせてある。
3. **真の採点除外は3問だけ**＝**NO.28・NO.111・NO.332**。うち残るのは
   **NO.332（113F-42・第12章 母子保健）**。この問題だけ
   ①バッジ `('bx','採点除外')` ②全選択肢 `ok=False` ③`rate=None`（`-1` や `0%` にしない）
   ④`ans_label='（採点除外）'` の4点セットで作る。
   ⚠️ **「※不正解者のみ採点除外」の4問（NO.15・33・272・616）は正解が存在＝通常扱い。**
4. **マークシートの計算問題6問**（**NO.207・218・238・245・259・263**＝第7章・第8章）。
   選択肢を持たず `ans_label` を **`計算答：<桁文字列>`** の形にする（`計算答：0.40` の
   先頭ゼロ・末尾ゼロは意味を持つ＝数値化しない）。
   ⚠️ この6問を入れたら **`_work/test_calc_input.js` の「選択肢を持たない問題は計算問題50件」を
   56 へ更新する**（更新しないとテストが落ちる）。
5. **画像の `chNN_map.txt` は連番が同一国試番号で全部 1 になる。**
   複数枚ある問題は 1..N へ振り直してから `save` する（振り直さないと上書きされて1枚しか残らない）。
6. **`compress_images.py` を無条件に流さない。** 既存2500枚超が2世代目の再圧縮になり巨大な差分が出る。

統合で触るのは **4か所**（章を足すたびに必ず全部）:

1. `gamify.js` の `ph` の `total`
2. `chapters_meta.js` に `ph_chNN`
3. `study.html` の `subj-hdr-count`（科目ヘッダの実数）
4. `sw.js` の `CACHE` と `SHELL_VERSION` を bump

表示確認（`file://` は不可）:

```bash
python -m http.server 8765 --bind 127.0.0.1
#  → http://127.0.0.1:8765/study.html?sid=ph
```

⚠️ **IndexedDB の `mec_subj_cache` を `deleteDatabase` で消さないこと。**
その origin の IDB が丸ごとジャムして study.html が「読み込み中…」から進まなくなる
（Chrome再起動まで直らない）。版管理は `sw.js` の `CACHE` 名で自動的に効く。
詰まったら別ポート（`localhost:8766`）で開く。

最後に、**解説はPDFに無くAIが書いたものなので、医学的正確性の抜き取り確認をユーザーに依頼する**
一文を添えて章を閉じる。
