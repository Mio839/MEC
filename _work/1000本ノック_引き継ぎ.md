  （`📎 ○○ Q.n の解説（同じ国試問題）` ＋借用元の eg）。判定は `build_hisshu_json.pick_source`、計算問題は桁文字列の一致。

## 再生成

```bash
python _work/knock_pdf.py anstable          # 巻頭リスト p.5〜24 → _work/knock_anstable.json
python _work/knock_pdf.py parse             # 本文 p.30〜301   → _work/knock_parsed.json
python _work/build_knock_json.py --figs     # 図を 1000本ノック/images/（解説の図は images/ex/）へ
python _work/build_knock_json.py            # questions_knock.json（--check で一致確認・--report で借用なしの一覧）
python _work/build_image_dims.py && python _work/build_qmeta.py && node _work/build_natrate_index.js && node _work/build_dup_index.js
python _work/pdf_audit.py knock             # 0件
```

⚠️⚠️ **questions_knock.json は派生物——直接編集しないこと。** 手書きは `_work/knock_overrides.json`（uid キー・未作成）か生成器の定数へ。
⚠️ **借用元の科目の解説を直したら、この科目も作り直すこと**（借用は生成時のコピー。run_all の `--check` が見張る）。
⚠️ `build_hisshu_json.NO_BORROW` に `knock` を入れてある（必修講座が knock を借用元に選ぶと二重になる）。

## 版面と罠

- 1ページ＝見開き（幅 1032pt）。**左半分＝問題、右半分＝同じ番号の解説**。見出しは「N.\t（118F-11）」／「N.\t（118F-11）テーマ」＋「解答：d」。
  テーマが2行に折り返すと「解答：」は2行目に来る（NO.700・701・787）。
- 組版の制御文字（NO.961「ｅ」の直後の BEL）とゼロ幅文字は `knock_pdf._ctl` で落とす。
- **下線として拾える細い横線は、NO.799（下線部のうち…）以外すべて表の罫**。生成器の `UL_OK` 以外は `<u>` を外す。
- 表が選択肢の問題は列見出しを各肢に埋め込む（自動）。自動で組めない3問（420 基準値の段・892 表と選択肢が同じ高さ・910）は `TABLE_CHOICES` に手で書いた。
  見出しが2段・結合セルの表（828・850・852・853）は `QT_FIX` に手で組んだ。いずれもページを描画して書き起こした。
- 計算問題18問：解答欄「解答：①.②」と「①1, ②3」から `計算答：` を作る。NO.531 は「①, ② ③ 0 kcal」＋位取りの2行を1行の注記に畳んだ（`QT_SUB`）。
- **3枚以上の図（画像が選択肢・連続スライス）19問はラベル①〜⑤／A〜F ごと1枚に切り出す**（`combine_figs`。重なる選択肢の行は白で消す）。
  1枚ずつだとラベルが消え、並びも位置順とずれる（NO.85・891）。`pdf_audit.py` の `VECTOR_RENDERED['knock']` に登録済み。
- 解説の図3枚（NO.6・457・814）は注記が画像の外の文字なので `knock_pdf.EX_FIG_CLIP` の範囲で切り出し、範囲内の文字は本文に入れない。
- 「示す」とあるが図の無い19問は表・動詞の「示す」（`NO_FIG_OK`）。ベクター描画の図が無いことは走査で確認済み。
- 複数正解（NO.118・163・184）は最初の組を ok にし、`ans_label` に「複数の選択肢を正解とする：…」を添える。NO.964 は「（当時はc）」を添える。
