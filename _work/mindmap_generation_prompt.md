# MEC 科目マインドマップ 生成プロンプト

以下の仕様で「{科目名}」の疾患マインドマップを作成してください。
血液のマインドマップ（血液/mindmap.html）を完全な参考実装として流用し、
データ部分（CHAPTERS・RELATIONS・色・リンク）を{科目名}用に書き換えてください。

---

## 参照ファイル

血液/mindmap.html（完成版）を必ず先に Read してから作業してください。

---

## レイアウトパラメータ（変更禁止）

```javascript
const CX = 800, CY = 660;
const R1 = 230;   // 章ノードの配置半径
const R2 = 600;   // 疾患ノードの配置半径
const W = 1600, H = 1380;  // SVGキャンバスサイズ

// ファン角度（これ以上広げると隣章のノードが衝突する）
const fanDeg = Math.min(36, 8 + 6 * total);

// 疾患ノードサイズ
const nodeR = 32;

// ラベルオフセット（ノードから文字まで）
const lx = nx * (nodeR + 20), ly = ny * (nodeR + 20);
```

**なぜこの数値か：**
8章構成で各章が45°間隔のとき、fanDeg=36°にすると隣章との間に9°（≒94px）の余白が生まれる。
これより大きくすると隣章の疾患ノードと衝突する。R2=600 で同章内6疾患でも約11pxの隙間を確保できる。

## 色分けルール

各章を「病態系統」でグループ化し、系統ごとに色を統一する。

| 系統 | 色の目安 | 例 |
|---|---|---|
| 炎症・感染 | 赤系 `#DC2626` など | 感染症・炎症性疾患章 |
| 腫瘍・悪性 | 青系 `#1D4ED8` など | 悪性腫瘍・白血病章 |
| 代謝・内分泌 | 橙系 `#D97706` など | 代謝・ホルモン章 |
| 自己免疫・アレルギー | 緑系 `#047857` など | 膠原病・アレルギー章 |
| 治療横断 | 紫系 `#7C3AED` など | 治療・薬理横断章 |

凡例（.legend）にも「色 ＝ 系統名」の説明行を追記すること。

## データ構造

### CHAPTERS

各章に以下を必ず設定する：

```javascript
{
  id: 'ch01',
  label: '章タイトル（5字以内推奨）',
  color: '#色コード',   // 上記の系統色
  angle: -90,           // 8章なら -90,-45,0,45,90,135,180,225 を順に割り当て
  link: 'ch01_xxx.html',
  diseases: [
    {
      id: 'd01a',
      label: '疾患名（括弧つきでも可）',
      imgs: ['images/xxx.jpeg'],  // 問題集から流用できる画像があれば設定、なければ []
      keys: [
        '国試頻出ポイント1（検査値・数値・略語を含む具体的な記述）',
        'ポイント2',
        'ポイント3',
        'ポイント4',
      ]
    },
  ]
}
```

章が8章でない場合の角度配分：
- 6章：-90, -30, 30, 90, 150, 210
- 7章：-90, -38, 13, 64, 116, 167, 218
- 8章：-90, -45, 0, 45, 90, 135, 180, 225
- 9章：-90, -50, -10, 30, 70, 110, 150, 190, 230
- 10章：-90, -54, -18, 18, 54, 90, 126, 162, 198, 234
- 11章：-90, -57, -24, 9, 42, 75, 108, 141, 174, 207, 240

### 画像の調べ方

```bash
# 章HTMLから画像パスを抽出
grep -oE 'src="[^"]+\.jpeg"' {科目}/{章ファイル}.html

# 疾患ごとの画像紐付け確認（data-uid属性と<img>の位置関係を目視で確認）
grep -n 'data-uid\|src=.*jpeg' {科目}/{章ファイル}.html | head -60
```

### RELATIONS（横断リンク）

国試で「鑑別」「合併」「転化」として問われる関連を設定する。

```javascript
const RELATIONS = [
  // 異章間（ラベルあり・点線＋背景付きテキスト）
  { from:'d01a', to:'d03b', label:'鑑別名', color:'#FBBF24' },

  // 同章内（ラベルなし・点線のみ） ← ラベルは文字重複するため非表示
  { from:'d02c', to:'d02d', label:'', color:'#93C5FD' },
];
```

**弧の方向（変更禁止）：**
- 同章内：中心から外向きに130pxのベジェ制御点（ノードの間を通らないように）
- 異章間：中心に向かって35%引き込む制御点（放射状外周を横断する弧）

## 画像ノードの仕様

| 条件 | 表示 |
|---|---|
| `imgs.length > 0` | SVG clipPath で円形クロップ ＋ 章色リング ＋ 外側ラベル |
| `imgs.length === 0` | 章色塗りつぶし円 ＋ 内側略称テキスト（英字4字まで）＋ 外側ラベル |

---

## インタラクション仕様（変更禁止）

- **複数章同時展開**：`activeChapters = new Set()`（タップで on/off トグル）
- **章タップ → 自動センタリング**：cubic ease-out、480ms
- **疾患タップ → 右下パネル表示**：国試ポイント＋画像サムネイル
- **画像タップ → lightbox拡大**
- **関連線**：両端の章が両方展開しているときのみ表示（フェードイン 0.4s）
- **ピンチズーム・マウスホイールズーム・パン対応**（iPad/スマホ/PC対応）

## index.html への追加

生成後、`index.html` の `MINDMAP_TOOL.maps` 配列に1行追加する：

```javascript
{ subject: '{科目名}', href: '{科目}/mindmap.html', color: '{代表色}', icon: '{絵文字}' },
```

---

## 重要な制約（開発中に判明した問題の防止）

1. **fanDeg は36°上限を守る**（超えると隣章ノードと衝突。数式で確認済み）
2. **同章内関係ラベルは表示しない**（点線のみ）— ノード間に文字が重なる
3. **updateRelations で `rel._label` アクセスは必ず `if (rel._label)` ガードを入れる**
4. **MINDMAP_TOOL に `chapters` プロパティは不要**（`getSubjectProgress()` が落ちないよう `|| subject.id === 'mindmap'` 分岐を確認）
5. **章が8章より少ない/多い場合は角度配分を再計算し、隣章との間隔が45°以上になるよう注意**
