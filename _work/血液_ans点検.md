## 手順（1回ぶん）

1. `PYTHONUTF8=1 python _work/hema_audit.py dump N N+5`
2. 1問ずつ、**まず設問文と照合**（存在しない数値・左右や向きの取り違え・否定形の読み違え・症例文が否定している診断）。
   次に**画像がある問題は画像を必ず Read で開いて見る**（循環器・内分泌で最も多かった誤りは「画像を読まずに書いた ans_sub」）。
3. 迷ったら PDF の解説（`pdf` でページを探し `render` で描画して目視）。**PDF が正本**。
4. 直すものは scratch に `edits.json`（`{uid: {"ans_sub": "..."}}`）を書いて `apply`。
   - 直すのは原則 `ans_sub` だけ。書式は既存と同じ1〜2行の要約（「A→B」「〜＝〜」）。
   - 設問文の**混入物**（紙面のページ番号・別問題の文）は見つけたら取り除く（文字の書き換えはしない）。
   - eg（本文）が ans_sub と同じ誤りを言っていたら、その文だけ直す（書き足しはしない）。
5. 下の進捗表に1行足す（誤りが無くても「誤りなし」と書く）。
6. 1章終わるごとに `python _work/pdf_audit.py hema --no-image` → `sw.js` の `CACHE` を bump → commit → push。
