## 採点データの不変条件（試験モードが壊れる原因になる）

試験モードの必要選択数は **`.ch2.ok` の個数**（`_getRequiredCount()`・study_exam.js）で決まる。
`ans_label` や「Nつ選べ」バッジは採点に一切使われない。したがって:

- **`ok` が1つも無い問題は、何を選んでも不正解になる**（例外を出さず黙って全問不正解）。
  2026-07-09に呼吸器ch02〜ch09の429問がこの状態で、以前から「正解でも不正解」と報告されていた原因だった。
- 選択肢は `a`,`b`,`c`… の順で1つずつ独立した要素であること。`"a　①　/　b　②"` のように結合していると選べない。
- `ok` の個数は問題文末尾の「Nつ選べ」と一致すること（`複数正解`・`採点除外` バッジのある問題を除く）。
- 📷バッジ（`bi`）と `imgs` の有無は必ず一致させること（🖼️フィルタの根拠）。
  2026-07-24に jitsu1 53問・custom 8問で欠落が見つかり `_work/fix_missing_bi_badges.py` で修正した。
  同スクリプトを `--dry-run` で流せばいつでも検出できる（現在0件）。
- `N択` バッジは PDF の `↗N`（画像枚数と無関係の内部マーカー）を誤読していたことがある。**正解数の根拠は問題文の「Nつ選べ」のみ**。
- 連問の図は右段にまとめて置かれ、図の直下に `A` `B` `C` のラベルが描かれる。**帰属はラベル文字の座標で決めること**（読み順=A,B,C とは限らず、実際に `B A` の順で並ぶ紙面がある）。⚠️⚠️ **表示側の規約は2026-09-06に変わった——ステムの図は「そのステムを表示する兄弟全員」に付ける。**
  連問は共通ステムを**全兄弟の qt へ丸ごと展開する**（整形外科式）ので、「心エコー図（A，B）を示す。」の一文は
  2問目・3問目の画面にも必ず出る。旧規約（ステムの図は連問1問目だけ）だと**図を参照する文だけがあって図が無い**
  問題が残り、循環器で6件のエラー報告になった。**設問Mが持つ図＝Mの qt に含まれる図の宣言文に対応する図すべて**
  （並びは宣言文が出てくる順＝A→B→C）。枝分かれ（「その後の経過：」で別の話になる兄弟）は宣言文を含まないので
  何も足さない。適用は `_work/_circ_tmp/propagate_series_imgs.py`（冪等・`--dry-run` あり）が参照実装。
  ⚠️ ファイル名は図を持ち込んだ設問の国試番号のまま（`111H-33_1.jpeg` が `111H-34` にも付く）。
  `pdf_audit.py` は**同じ連問グループの兄弟の番号なら不一致として挙げない**ようにしてある（誤帰属の検出は残る）。
  ⚠️ **imgs を足した設問には 📷 バッジ（`bi`）も足すこと**（バッジと imgs の一致は監査項目）。

### 欠落選択肢のPDF復元（2026-07-26）

`python _work/extract_missing_choices.py` で抽出・検証 → `python _work/apply_missing_choices.py` で適用。
⚠️ この2本は `.gitignore` の `extract_*.py` / `apply_*.py` に該当し**Git管理外**（マシンローカル）。
別マシンでは再作成が必要。以下の知見はそのための記録でもある。
**テキストの並び順ではなくPDFのブロックを見る**のが要点。MEC解説集は1問が
「設問文＋選択肢」「着目point」「選択肢考察」「正解」「正答率（選択率）」の独立ブロックに
分かれており、素のテキスト順で切ると最後の選択肢（ｅ）が解説を飲み込む。

信頼度は PDF が持つ独立な3情報と `ans_label` の一致で判定する:
「正解」ブロック／選択率が最大の肢／全体正答率が `data-rate` と一致。2つ以上一致で `ok`。

- ⚠️ **`○`/`×` マーカーは検証に使えない**。MEC は「その記述が正しい」の意味で使う紙面と
  「これが正解」の意味で使う紙面が混在する（`116C-41` は `×ｃ` が正解、`116B-15` は `○ｄ` が正解で
  どちらも否定形の設問）。参考情報としてだけ出す。
- ⚠️ 検証材料はページ全体から拾ってはいけない。1ページに2問載る紙面があり前の問題の正解を
  拾う（`116C-41`）。次ページを無条件に足すと次問のマーカーを拾う（`116B-15`）。
  **選択肢ブロックの直後から「正答率」ブロックまで**で閉じる（`verify_region`）。
- 選択肢ラベルの直後は **U+0001**（PDF・過去問HTMLの qt 共通）。空白決め打ちでは切れない。

## 既存科目のHTMLを作り直すときの不変条件（2026-08-28〜）

⚠️⚠️ **作り直しの対象は「解説」だけではない。設問文(qt)・画像・バッジ・rate_text の4つを必ず同じパスで作り直す。**
2026-08-28 にユーザーが決めた方針で、循環器（circ）の作り直しが最初の適用先。以後どの科目を作り直すときも同じ。

### 画像は既存を1枚も信用せず、PDFから抽出し直して目視で突き合わせる

⚠️⚠️ **「監査が通っているから画像は正しい」は成り立たない。** `pdf_audit.py` の画像照合が見ているのは
**「その画像ファイルがPDFのどこかに在るか」だけ**で、**「この設問の図か」は一度も検証していない**。
帰属の誤り（隣の設問の図・別ページの図）はこの監査を素通りする。実際、循環器は
`pdf_audit.py circ` が画像10件を「PDF内のどの図とも一致しない」と出す一方、
**ファイル名と国試番号の不一致は0・実体欠落も0**＝名前だけ揃っていて中身が保証されていない状態だった。

- **全画像をPDFのページ描画と1枚ずつ目視で突き合わせる**（設問と図が一致しないと学習ツールとして機能しない）。
- **「〜を示す」と書いてあるのに `imgs` が空**の問題を必ず洗い出す（循環器は厳密判定で29問あった）。
- 連問の図は**そのステムを表示する兄弟全員**へ付ける（2026-09-06に規約変更。上記「連問の図」を読むこと）。
- 抽出ツールは `ortho_pdf.py` の `images`（矩形＋帰属候補＋ページ描画）／`save`（mapに従って保存）方式が正本。
  ⚠️ **臓器別講座はマイナー講座と版面が違うので座標系をそのまま流用できない**（`circ_pdf.py` には
  そもそも画像コマンドが無い＝科目ごとに作る必要がある）。

#### 手順は「整形外科式」＝機械が帰属候補を出し、ページ描画で人が検収する

科目によってやり方が違うので、どちらを踏襲するかを間違えないこと。

| | 目視の入り方 | 成立した理由 |
|---|---|---|
| **整形外科・耳鼻科・泌尿器科・眼科** | 機械が矩形と帰属候補を出し、**同時に出したページ描画(110dpi)を見ながら `ch{NN}_map.txt` を1行ずつ検収**してから save | 帰属は機械では決めきれない（図ラベルA/Bの左右はx座標、連図の順は紙面依存） |
| **産婦人科** | **ほぼ全自動**。目視は例外9件だけ（図が無いのに `has_image=True` が2件・ベクター描画で手作りPNGが2件・`has_image` 補正5件） | `obg_questions.json` の **`has_image` という独立した権威**があった |

⚠️ **産婦人科式（全自動）を、権威を持たない科目へ持ち込まないこと。** 作り直しでは `imgs` 自体が
疑いの対象なので、`has_image` に相当するものが存在しない。**整形外科式が既定。**

⚠️⚠️ **作り直しでも既存画像を先に消さないこと**（2026-08-28 に検討して却下）。理由:

1. コストの主因は**画像を含むページの帰属検収**（循環器は p5-361 のうち **214ページ**・埋め込み画像は
   延べ369枚）で、フォルダが空でも同じだけかかる。消しても安くならない。
2. **既存ファイルは無料の照合材料**になる。新規抽出と一致したページはその場で確定でき、
   **食い違ったページだけが疑わしい場所として浮かび上がる**＝残した方が検収は速い。
3. ⚠️⚠️ **`pdf_audit.py` の「PDF内のどの図とも一致しない」を「ベクター描画だから復元できない」と
   読まないこと（2026-08-28 に否定された）。** 循環器の10件は実際には**全部が PDF の埋め込み
   raster と完全一致**していた（正規化相関 ncc=0.9996〜0.9998・うち8件は dhash 距離すら 1〜4）。
   原因は判定側で、**dhash は隣接画素の勾配を見るので心電図の方眼のような細かい周期模様では
   同じ図でも再エンコードで符号が反転して閾値(6)を越える**。この誤検出は
   `pdf_audit.py` に **ncc の第二段**を足して潰した（dhash が外れた画像だけ相関で取り直す）。

**残ったファイルの掃除は最後に1回**——全章を作り直し終えた時点で `imgs` から参照されていない
ファイルだけを削除する。

**機械照合を3つ併用する**（整形外科・産婦人科のどちらにも無かった）。
循環器では**572問中541問が①と③の一致だけで確定し、目視が要ったのは28問**まで絞れた:

1. **同一性** — 既存ファイルが PDF のどの xref かを突き止める。⚠️ **ahash / dhash 単独で判定しない**
   （上記3のとおり心電図で必ず外れる）。ahash で候補を8件に絞り、**正規化相関(ncc>0.90)で確定**する。
2. 巻末解答一覧表の**「疾患名」列**との整合（眼科で確立。心電図・心エコーの読みの裏取りに効く）
3. **設問文が宣言する枚数**と `imgs` の枚数（「胸部エックス線写真（A）と心電図（B）とを示す」＝2枚）。
   ⚠️ 連問は①で共通ステムが**全兄弟の qt へ展開済み**なので素朴に数えると兄弟全員が
   ステムの図を要求する。**共通ステム＝兄弟の qt の最長共通接頭辞**を取り、
   ステムぶんは**兄弟1人ぶんとして1回だけ**数えること（枚数の検算の話。**表示は兄弟全員に付ける**のが
   2026-09-06以降の規約で、ここと矛盾しない）。
   ⚠️ 「異常所見を示す心臓の部位」の「示す」はただの動詞。**文末の「〜を示す。」だけ**を数える。

- ⚠️⚠️ **帰属を矩形のy座標で決めないこと。** 臓器別講座は**右段組み**で、図は右段に縦に積まれ
  左段の設問アンカーと高さが揃わない。しかも連問は「共通ステム → 図 → 各設問」の順に組まれるので、
  **ステムの図は最初の設問アンカーより上に来る**。幾何だけで決めると循環器で25問が誤判定になった。
  **正本は設問文**（どの設問が「〜を示す」と書いているか）で、幾何は候補出しに留める。
- ⚠️⚠️ **複数枚の問題は「並び」も検収すること。** 図ラベル(A/B/C)は画像の外に組まれた文字なので
  **切り出した画像には写らない**。並びが狂うと「A のつもりで B を見る」形で静かに壊れ、
  枚数チェックでは絶対に見つからない。循環器では**100問中21問**が狂っていた（多くは
  `_1`＝右の図・`_2`＝左の図）。⚠️ **位置で並べ替えて済ませないこと**——紙面には図が
  `B A` の順に組まれることが実在する（NO.401 は B が上・A が下）。**矩形の直下のラベルを拾って
  ラベル順に並べる**のが正本。ラベルがベクター字形でテキスト抽出できない紙面（NO.331 の①〜⑤）だけ
  目視で決め、決めた事実を残す。
- **並びの直し方はファイルの中身を入れ替える**（`_1` に図Aを、`_2` に図Bを保存し直す）。
  `imgs` のリストの方を並べ替えると、ファイル名の連番と図ラベルの対応が崩れて後から読めなくなる。
- ⚠️ **保存し直すのは中身が変わるファイルだけ。** 同じ図でも再エンコードでバイト列が変わるので、
  全部を保存し直すと 350枚中341枚が `M` になり、本当に直した20枚を探せない差分になる。
- ⚠️ **図を足した／外した問題は 📷バッジ(`bi`) も一緒に直すこと**（`imgs` の有無と一致必須）。
- 画像を差し替えたら **`build_image_dims.py` の再生成**と **`sw.js` の `CACHE` bump** が必須
  （ファイル名を変えないので、bump しないと全端末が古い画像を掴み続ける）。

### 設問文(qt)は「整形外科・耳鼻咽喉科式」に揃える

新10科目（ortho/ent/oph/derm/psy/uro/anes/rad/tox/ph）と産婦人科の形が正で、旧コア12科目の形は古い。

| | 正（整形外科式） | 旧（循環器にあった形） |
|---|---|---|
| 設問文 | **1文まるごと `<strong>`** | 否定語だけ `<strong>`（circ は全体strongが572問中77問＝13%しかなかった） |
| 連問の共通ステム | **qt へ直接展開**。先頭に `<span class="kw">次の文を読み、Q.99〜Q.101 の問いに答えよ。</span><br/>` | `<span class="qt-context"><span class="series-label">連問 1/2</span>…</span>` |
| 改行 | 文として自然に流す | PDFの折り返しが `<br/>` で残る（circ 112問） |
| 項目見出し | `<b>現病歴：</b>` `<b>現　症：</b>` 等 | 素のテキスト |
| 単位 | `SpO<sub>2</sub>` | `SpO2` |

- ⚠️ **`qt-context` / `series-label` を新しく書かないこと**。`vars.css` にスタイルは残っているが
  （旧コア12科目の633問が使っているため消せない）、`white-space:pre-line` と PDF の折り返しが合わさって
  紙面の改行がそのまま画面に出る。作り直した科目では使わない。
- ⚠️ **PDFの折り返しを消すのは「原文改変」ではない**。あれはレイアウト由来で本文の一部ではないので、
  取り除いた方が原文に近い。**文字そのものは1字も変えないこと。**
- **qt 内の `kw` 強調（症例文の鍵になる所見を光らせる）は任意**。判断がつく問題だけでよく、
  **付いていないことを理由に書き直させない**（2026-08-28 ユーザー判断）。付けるときは
  **原文の文字を1字も変えず span で囲うだけ**——タグを剥がした素文がPDFと一致することを機械検査できる形を保つ。
