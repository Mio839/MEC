## 模試の自己採点（2026-09-08〜）

`mock.html` ＋ `mock.js` ＋ `mock_data/`。解説書PDFから起こした解答表を持ち、マークシートから
解答を転記して**一括採点**する。テスト: `node _work/test_mock_score.js`（41件）＋
`_work/test_mock_browser.html`（実ブラウザで26件・下記）。
章ごとの作業ノート・PDFの座標・解説HTML化の入口は **`_work/夏メック模試_引き継ぎ.md` が正本**。

現在入っているのは **第121回 夏メック模試（`m121s`・A〜F 400問500点・禁忌肢17問・計算3問・連問20群）**。

### ⚠️ 正誤を保存しないこと

保存するのは **「何を選んだか」（`p`）だけ**で、正誤も得点も `mec_mock_v1` に入れない。
正誤は `mock.js` の `judge()` が解答表と突き合わせて毎回計算する。

- 狙いは**正誤の式がソースの1か所にしか無い状態を保つこと**。解答表を直せば過去の記録も
  自動で正しくなる＝記録が黙って古いままにならない。
- 同期のマージも軽くなる（解くべき衝突が「1問ぶんの解答」だけになる）。
- ⚠️ 「速いから」「集計が楽だから」と正誤や得点を書き戻さないこと。

### ⚠️ 自動送りの条件に「正解の数」を使わないこと

肢を選ぶと自動で次の問題へ送るが、その条件に使ってよいのは **`q.pick`＝設問文の「Nつ選べ」**
だけ。**正解数（`q.ans.length`）を使うと、入力しただけで正解の個数が漏れる**。
`pick` は受験者が問題冊子で見ている情報なので漏洩にならない。

- ⚠️ `pick` と `ans.length` は実データで全400問一致しているので、うっかり `ans.length` に
  差し替えても**動作は変わらず気づけない**。だからここに書いてある。
- 同じ理由で、**採点前は禁忌肢問題であることも出題テーマも出さない**（転記の記憶が揺れる）。

### ⚠️ 未入力ブロックは満点にも母数にも入れない

`score()` は**解答が1問でも入っているブロックだけ**を合計する。A〜Cしか解いていない日でも
意味のある数字が出るのがこの設計の目的で、必修の母数も B だけなら100点満点になる。

- ⚠️ 逆に言うと「1問も入れていないブロックは満点が減る」ので、**表示側は入力済みブロックを
  必ず明示すること**（`mock.html` は総得点の直下に出している）。

### ⚠️ 合否の基準は「制度の値」だけを既定値にする

必修80%・禁忌肢4問で不合格は制度の値なので `mock.js` に定数で持つ。
**一般・臨床のボーダーは持たない**（模試の推定ボーダーは配点表に載っていない）＝
ユーザーが `border()` に入れたときだけ判定する。⚠️ 推測値を既定にしないこと。

### ⚠️ 設問の図は解説書PDFに入っている（別冊は要らない）

「別冊No.○を別に示す」と書かれていても、**解説書PDFでは設問文のすぐ後にその図が挿入されている**
（2026-09-08にユーザーが指摘・実測で確認）。**画像問題の図は別冊を待たずにPDFから抽出でき、
今後つくる解説HTMLではそうすること。** 対象は122問・131種で、在りかは各設問の `pdf[0]`
（連問はグループ先頭ページ）。⚠️ 4問だけベクター描画なので `get_images()` では取れない。
詳細と罠は `_work/夏メック模試_引き継ぎ.md` §3-3。

### 解説の重さ ＝ `MecMock.weights()` が唯一の出口

今後つくる解説HTMLはこれだけを読む（0=正解 / 1=誤答 / 2=未解答 / 3=禁忌肢を踏んだ）。
⚠️ **段を増やすときは `weights()` とそのコメント表の両方を直し、HTML 側に閾値を書かないこと。**

### ⚠️ データは3つの独立な検算を通っている

`_work/build_mock_m121s.py` は解説書PDFの独立した3か所を突き合わせる:
① 配点区分の合計＝解答表下の記載 ② 解答表の禁の印＝科目別一覧表の禁忌列（17問で一致）
③ 設問文の「Nつ選べ」＝正解の個数（400問で一致）。
**この一致は「読み取りが壊れていない」ことの証明**なので、通らなくなったら黙って通さず落とす。
`test_mock_score.js` の §1〜§3 が生成物の側からも同じことを見張る。

## 模試の解説（2026-09-09〜・questions_m121s.json）

`_work/build_mock_m121s_json.py` が解説書PDFから**全400問**を起こす。設計と経緯の正本は
`_work/夏メック模試_引き継ぎ.md` §6。テスト: `node _work/test_mock_questions.js`（24件）。

### ⚠️ questions_m121s.json は純粋な派生物——直接編集しないこと

手書きの解説（誤答65問を循環器品質で書き下ろすぶん）は **`_work/mock_m121s_overrides.json`**
に uid をキーにして置き、**生成の最後にマージする**（2026-09-08 ユーザー裁定）。
直接書き込むと、PDFの読み取りを直して再生成した瞬間に消える。

```bash
python _work/build_mock_m121s_json.py            # 書き出す（手書きを重ねてから検算）
python _work/build_mock_m121s_json.py --block A  # A問題だけ検算（書き出さない）
python _work/build_mock_m121s_json.py --figs     # 画像診断の図を 夏メック模試/images/ex/ へ
python _work/build_mock_m121s_json.py --check    # 現物と一致するかだけ見る
```

### ⚠️ uid の対応は `MecMock.studyUid()` が唯一の正本

採点ツールの uid（`m121s_A_q17`）と解説の uid（`m121s_ch01_q17`）は**別物**。
対応は「ブロックの count を積む」規則1本で、`mock.js` の `studyUid()` と生成器の両方が
同じ規則を持ち、テストが一致を見張る。⚠️ **章頭の通し番号（A:1 B:76 C:126 …）を
どこかに書き写さないこと**——ブロックの問題数から決まる値なので、数字で持つと腐る。

### ⚠️⚠️ MEC の ○/× は「正解の印」ではない

選択肢考察の ○/× は**その記述が正しいかどうか**であって「これが正解か」ではない。
否定形の設問（「〜でないのはどれか」）では **× の肢が正解**で、実測**68問**がそうだった。
- `ans_sub`（✅ の直下）は **正解の肢**の考察を引く。○ の行ではない。
- 選択肢考察の表で緑（`kw3`）に光らせるのも**正解の肢**。紙面の ○/×/□ の印は
  そのまま先頭に残す（印は紙面の事実、緑は正解という別の軸）。

### ⚠️ 禁忌肢はカードの見出しに出さない

禁忌肢17問に専用バッジは付けない。解説を開く前に「踏んではいけない肢がある」と分かると
それ自体がヒントになる（`mock.js` の「採点前は禁忌肢問題であることを出さない」と同じ理由）。
紙面の `□` 印は**選択肢考察の中＝正解を見た後の場所**にだけ残す。テストが見張る。

### バッジ

`bb`（新設・桃）＝紙面の問題番号「A問題 17」。表示番号 `Q.n` は科目内の通し番号なので、
マークシートと突き合わせる番号をここで別に出す。ほかは既存のものを使い回す——
`bh` 必修（B・E の100問）／`bip` 一般・`brn` 臨床／`bsub` 科目（`cat2`）／`bm` N択／
`bk` 計算（桁入力3問）／`bi` 📷画像。⚠️ クラス名は `bg`（土台）・`br`（連問）と衝突させない。

### ⚠️ 解説の図（`夏メック模試/images/ex/`・140枚）は設問の図と別物

「画像診断」ブロックの**注釈付きの図**（矢印と標識入り）で、答えそのものなので
**解説ブロックの中**に出す。設問の図（`q.imgs`・素の写真138枚）は選択肢より**上**に出る。
- ⚠️ **`q.imgs` に入れないこと**（選択肢より上＝答えが先に見える）。
- ⚠️ `class` は `qimg exfig`。`qimg` はライトボックスが掴む名前なので外さない。
  一方で**行を `.qimg-row` にしないこと**——「🖼️画像だけ」フィルタの `hasImg` が
  `.qimg-row .qimg` を数えており、解説に図があるだけで画像問題に化ける。
- ⚠️ 説明文（「写真A　…」）と図は**紙面と同じ交互の並び**で入れる。文を先にまとめると
  どの説明がどの絵か読めない。
- ⚠️ 図に添えられた注記（矢印の先の「顆粒状隆起性病変」）は**図の一部**。本文から外して
  clip へ畳む。残すと語が説明文に紛れ、絵からは切れて矢印だけが残る（両方で壊れる）。
- ⚠️⚠️ 注記を畳む相手は**同じページの、一番近い図**。ページを見ないと別ページの図へ
  吸い込まれて消え（F70）、近さを見ないと隣の図の説明文まで巻き込む（A38）。

### ⚠️ 選択肢が表の2問（A65・D46）は生成器の定数が正本

`TABLE_CHOICES`。表のまま置くと試験モードの肢シャッフルで対応が崩れるので、
**列見出しを各肢に埋め込み**、単位は設問文の末尾に注記する（CLAUDE.md
「表・図の選択肢の復元」と同じ流儀）。⚠️ 選択肢は `esc()` で描かれるので**HTMLタグは
使えない**——上付き下付きは Unicode（`₂ ₃ ⁻ ⁺`）で書く。

### この模試には正答率が無い

解説書の全772ページを走査して「正答率」は0件。`rate: -1` / `rate_text: ''` なので、
難易度フィルタ（難問/標準/易問）と `_isHardCard` には掛からず「正答率なし」に入る。
これは欠落ではなく模試の性質——**推測値を入れないこと**。
