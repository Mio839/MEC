### 1問あたりの手順

1. 画像を **全部**開く（`産婦人科/images/*.jpeg`）。細部が要るときは PIL で crop → 4倍拡大。
   PDF の埋め込みは 591×469 程度＝**ファイルが既に原寸**なので、PDFを描き直しても増えない。
2. 📸 ブロック（多くは `eg[0]`）を、**実際に見えているものだけ**で書き直す。
3. ⚠️ **番号（①〜⑤）や記号（A/B）に意味を割り当てている解説は、対応が合っているか必ず確かめる。**
   見ずに書かれた解説は**対応を創作している**（下記の実例）。ずれていたら `em`（選択肢解説）も直す。
4. `ans_sub` が画像と矛盾していないか見る。

### ⚠️ 実際に踏んだ罠

- **111H-18（器具①〜⑤）**：旧解説は「①クスコ式腟鏡／②子宮ゾンデ…」と割り当てていたが、
  実物は **②がクスコ式腟鏡**。正解肢 ①の説明そのものが誤りだった。
- **114F-33（EFWの断面）**：旧解説は ③＝AC・④＝FL としていたが、実物は **③＝FL・④＝AC** で逆。
- **115B-8（ホルモンのグラフ）**：旧解説は「産褥期に高値を保つ」だけだったが、実物には
  **「吸啜刺激」の↓矢印6本と、それに同期した実線Aのスパイク**が描かれている＝これが唯一の決め手。
- **119A-11（腹腔鏡）**：画像に「子宮／左卵管／右卵巣／右卵管」の**標識が焼き込まれている**。
  左卵管だけが暗紫色に腫大し、Douglas窩に血液が貯留＝左卵管妊娠。左右の比較が読み方の核。

### ⚠️ 画像ファイルの並び順がずれている（別口の不具合）

複数画像の48問を PDF の版面順と知覚ハッシュで突き合わせたところ、**14問で `_1 _2 _3…` の順が
紙面の①②③…と一致していなかった**（`111H-18_1.jpeg` の中身が③だった等）。
検査と修正は下記。**`--fix` は全部まとめて直してしまうので使わない**——

⚠️ **並べ替えてよいのは「画像内のラベルを自分の目で見た問題だけ」**（CLAUDE.md
「表示側の規約」の *ラベルを拾ってラベル順に並べる*）。版面の位置順がラベル順と一致しない紙面が
実在するため、位置だけで機械的に並べ替えてはいけない。**その問題の画像所見を書くときに
ラベルを見るので、そのついでに直すこと。**

```bash
python _work/verify_obg_img_order.py  # 検査だけ（順序ずれの一覧）
```

⚠️⚠️ **この検査は「OK」を信用してはいけない（偽の OK が出る）。** 版面順を
`(行, 左から)` で並べているので、**2列×3行に組まれた設問では行優先に拾ってしまい、
実際の①②③…（列優先）と食い違ってもずれとして挙がらない**。実例: `115F-30` は
検査が OK と言ったが、実物は `_1=① _2=④ _3=② _4=⑤ _5=③` だった。
**挙がった問題は確かに怪しいが、挙がらなかった問題が正しい保証はない**＝
この一覧は「疑いのリスト」であって合格証ではない。**正本は常にラベルの目視。**

2026-09-20 時点で目視確認して直したのは **111H-18 / 114F-33 / 111G-4 / 105E-24 / 115F-30 /
107G-52 の6問**。⚠️ **115F-30 と 107G-52 は同じずれ方（`①④②⑤③`）だった**——5枚を
2列×3行に組んだ紙面で、ラベルは列優先なのに抽出が行優先になるためで、どちらも検査は「OK」と言った。
**5枚組を見たら順序を疑うこと。**
残りの順序ずれ（`obg_ch06_q264` `obg_ch07_q342` `obg_ch07_q349` `obg_ch10_q526` `obg_ch10_q558`
`obg_ch10_q570` `obg_ch10_q571` `obg_ch10_q578` `obg_ch10_q600` `obg_ch11_q619`）と
判定不能3問（`obg_ch05_q197` `obg_ch06_q253` `obg_ch07_q356`）は**未着手**。

⚠️ 画像の中身を書き換えたら **`python _work/build_image_dims.py`** と
**`sw.js` の `CACHE` bump** を必ず対で行う（ファイル名が変わらないので、bump しないと
全端末が古い画像を掴み続ける）。
