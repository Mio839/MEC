## 版面（PDF 固有の事情）

- 1段組み。右端の縦書き見出し（x>555）とヘッダー（y<45）は本文ではない。
- 節ごとに「〔　〕穴埋めのレジュメ（■/◇）」→「□□□ ＋ `N. （国試番号）`」の問題。
  同じページの上にレジュメ・下に問題が載ることが多い（区切りは □□□・■・◇ で判定）。
- 選択肢は1行に複数並ぶことも、記号「ａ」と本文が別の行として同じ高さに並ぶこともある
  → **同じ高さの行を束ねてから**（`merged_lines`）肢に切る。
- 設問文の段落: 字下げ＝新しい段落、「現病歴：」等の見出し＝新しい段落。見出しの段落は
  続きの行もぶら下げで字下げされるので、**直前の行が右端まで詰まっているか**で折り返しと見分ける。
- 下線部（①〜⑤の参照型）は**文字の直下の細い横線（図形）**として描かれている → 文字単位で `<u>` を復元。
  下付き（SpO₂・HCO₃⁻）は字の大きさ（9.2pt 中の 5.5pt）で判定。選択肢は esc() で描かれるので Unicode（₂ ⁻）へ。

## 解答表（p.242〜250）

- 列: NO. / 解答 / 国試番号 / 中小項目 / 出題テーマ / 疾患名 / 一般 / 臨床。**★・CBT・正答率の列は無い**。
- ⚠️ 見開きで表全体が約6pxずれる → ページごとに「NO.」見出しの x から差分を取る。
- ⚠️ 国試番号の下に注記が3行ぶら下がる行がある（NO.270 の「※複数の選択肢を正解とする」）。
  最も近い行で決めると前の行に吸われるので、国試番号は y 順に行と対にする。
- ⚠️ NO.37 だけ解答が全角「ｂ」。
- 特殊な3問:
  - NO.270（119E-28）「a or c」＝どちらも正解として採点 → ok は a だけ、ans_label に「ｃ も正解として採点」。
    既存の腎臓・過去問ビューアも a だけ ok にしている（選べる数が1なので2つ ok にすると解けなくなる）。
  - NO.287（112E-6）「※不正解者のみ採点除外」→ 採点除外の印は付けない（注記は ✅ の下に出す）。
  - NO.323（102F-15）「※採点除外」→ `bx 採点除外` ＋ ok=c（正解肢ありの採点除外＝通常採点）。

## 図（必修講座/images・20枚）

- 画像の範囲を**ページごと 300dpi で描き直している**（xref をそのまま保存しない）。画像に重ねた
