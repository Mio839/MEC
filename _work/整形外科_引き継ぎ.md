## 1. 道具（すべてGit管理下・すぐ使える）

```
python _work/ortho_pdf.py anstable          巻末解答一覧表(PDF p.109-112)を全174問ぶん抽出

python _work/ortho_pdf.py save   --ch N     ch{NN}_map.txt に従って 整形外科/images/ へ保存

python _work/build_ortho_json.py            全章HTML → questions_ortho.json

python _work/pdf_audit.py ortho             PDFを正本に中身まで照合（画像の知覚ハッシュ含む）
```

生成された `.txt` は **Readツールで読む**こと。

## 4. 1章を仕上げる手順（第1章で実際に踏んだ順）

```
1. python _work/ortho_pdf.py spec   --ch N     → Readで正解・正答率・バッジ・テーマを把握
2. python _work/ortho_pdf.py text   --ch N     → Readで問題文と選択肢を書き起こす
3. python _work/ortho_pdf.py images --ch N     → 帰属候補を見る
   ＋ fitz でページを150〜200dpiに描画して Read で目視確認（図が選択肢の問題は必須）
4. _work/_ortho_tmp/chNN_map.txt を目視結果に合わせて直す
```
