## 2. このPDF固有の注意（第1章でぶつかったもの）

### ⚠️ 左右端に章名の縦書きが1文字ずつ入る
「神」「経」「の」「障」「害」…が本文テキストへ混じる。`cmd_text` は
**x<40 / x>540 の単語を落として** dump するようにしてある。素の `page.get_text()` を
使うと問題文の合間に1文字ずつ挟まるので、必ず `ortho_pdf.py text` を通すこと。

### ⚠️ PDF p.4 は「MECマイナー講座の特徴」の見本ページで中身は精神科の問題
`CH` のページ範囲で限定しているので混入しないが、手で拾わないこと。

### ⚠️ 解答一覧表は p.109-112（印刷 p.106-109）
**列のx座標は psy/derm/oph/ent/uro と完全に同一**。`COLS` はそのままでよい。
国試番号索引は p.113-114。**印刷ページ番号 ＝ PDFページ番号 − 3**。

### ⚠️ 図の抽出順は必ず目視で確認する
第1章で食い違ったのは **NO.5(111B-40) の1問**（紙面 上段①②③(x=168/297/427)・下段④⑤に対し
`get_images()` の順は ②③①④⑤）。170dpiのページ画像で確認して `ch01_map.txt` で入れ替えた。
NO.22・NO.28(A/B) は抽出順＝紙面順で一致した。
**A/Bラベルは矩形直下の単語の x 座標で確定させる**（`cmd_images` が候補を出す）。

### ⚠️ 線画は q95 で保存される
`cmd_save` の `_is_line_art()` がほぼ無彩色の画像を判定して q95 にする（シェーマ・単純Ｘ線）。
q85 だと `pdf_audit.py` の知覚ハッシュ照合が閾値を超えて誤検出になる。**触らないこと。**

### ⚠️ `compress_images.py` は流さない
既存3200枚超を再エンコードして巨大な差分を作る。`cmd_save` が長辺1200px・JPEGまで落としている。

### PDF全体の性質（anstable で確認済み）
- **連問は4組**：NO.55-57／99-101／108-109／141-143 → **症例文は組の全カードに載せる**
- **複数選択27問**（2つ選べ17／3つ選べ10）
- **正答率が無いのは NO.15・16・17・157 の4問**（旧国試で出典に数字が無いだけ）
- **採点除外（解答＝なし）は0問**
- **選択肢が表形式の問題は第1章には無かった**。以降の章で出たら§1のとおり
  作業を止めてユーザーにスクリーンショットを依頼する

1. **末梢神経麻痺は「どの神経が・どこで・何を支配するか」の3点セット**
   — 正中神経/手根管、尺骨神経/肘部管、橈骨神経/上腕骨骨幹部、総腓骨神経/腓骨頭。

2. **頸髄損傷は「損傷高位 → 残る筋 → できるADL・使う自助具」で一直線**
   （C6以下なら手関節背屈が残る＝tenodesis actionでプッシュアップ・自助具が使える）。
3. **脊椎疾患は「痛みの出かた」で切る** — 神経根症（デルマトーム状の放散痛）／
   脊髄症（巧緻運動障害・痙性歩行）／馬尾症候群（膀胱直腸障害＝緊急）。
4. **側弯症は前屈テスト（Adams test）で肋骨隆起を見る**（NO.31・35・72が全部これ）。

## 4. 1章を仕上げる手順（第1章で実際に踏んだ順）

```
1. python _work/ortho_pdf.py spec   --ch N     → Readで正解・正答率・バッジ・テーマを把握
2. python _work/ortho_pdf.py text   --ch N     → Readで問題文と選択肢を書き起こす
3. python _work/ortho_pdf.py images --ch N     → 帰属候補を見る
   ＋ fitz でページを150〜200dpiに描画して Read で目視確認（図が選択肢の問題は必須）
4. _work/_ortho_tmp/chNN_map.txt を目視結果に合わせて直す
5. python _work/ortho_pdf.py save   --ch N     → 整形外科/images/ へ保存
6. _work/build_ortho_ch{NN}.py を build_ortho_ch01.py からコピーして執筆
   （Q_START・SECTIONS・タイトル・章番号を差し替える）
7. python _work/build_ortho_ch{NN}.py
8. python _work/build_ortho_json.py
9. python _work/verify_ortho_ch.py --ch N      → errors=0 warnings=0 まで直す
10. python _work/pdf_audit.py ortho            → 0件
11. 各所を実数へ更新（§5）
12. python _work/build_image_dims.py / python _work/build_qmeta.py
13. node _work/test_subject_totals.js / node _work/test_card_render.js（＋テスト一覧の全部）
14. 127.0.0.1 の http.server で表示・採点を確認（file:// では動かない）
15. commit（push はユーザーに確認）
```

### 品質基準（第1章の実測）

| 指標 | 基準 | 第1章の実測 |
|---|---|---|
| 解説ブロック数/問 | 3.8 | **4.00** |
| 解説文字数/問 | 500 | **1244** |
| kw強調/問 | 10 | **40.3** |

`Q()` に `patho`(ep) / `deep`(em) / `point`(ept) を渡し、`ee`（全肢検討表）は
`choices` の4つ組 `(letter, text, ok, why)` から自動生成される。**`why` を全肢に書けば
肢別解説の書き漏らしは起きない。**
