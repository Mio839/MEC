### 生成器の型（`build_ent_ch02.py` を雛形にする）

- 先頭に `Q_START = <章頭のNO.>`。カード番号は `Q_START + idx`、セクション見出しの「Q.a〜Q.b」も自動計算。
  **章ごとに Q.1 へ振り直さない**（`jumpToQnum` が壊れる）。
- `FW` は **a〜g** まで持つ（ch01 NO.19 が7択。5択決め打ち禁止）。
- `Q()` の中で **`imgs` があれば `('bi','📷')` を自動付与**する。手書きの badges に並べると必ず落ちる。
- `rate=None` にすると `.cr` スパンを出さない（正答率が無い問題用）。
- 1問4ブロック: `patho`(ep) / 自動生成の `ee` / `deep`(em) / `point`(ept)。
- `SECTIONS` の idx は 0始まりのチャプター内連番。PDFの「A問題（★問題）」「B問題（★問題）」
  「A問題」「B問題」の見出しが出るページで区切る。

  ステージは `git add -A` ではなくファイルを明示して行う。
