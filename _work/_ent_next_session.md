### 生成器の型（`build_ent_ch02.py` を雛形にする）

- 先頭に `Q_START = 51`。カード番号は `Q_START + idx`、セクション見出しの「Q.a〜Q.b」も自動計算。
  **章ごとに Q.1 へ振り直さない**（`jumpToQnum` が壊れる）。
- `FW` は **a〜g** まで持つ（ch01 NO.19 が7択。5択決め打ち禁止）。
- `Q()` の中で **`imgs` があれば `('bi','📷')` を自動付与**する。手書きの badges に並べると必ず落ちる。
- `rate=None` にすると `.cr` スパンを出さない（正答率が無い問題用）。
- 1問4ブロック: `patho`(ep) / 自動生成の `ee` / `deep`(em) / `point`(ept)。
- `SECTIONS` の idx は 0始まりのチャプター内連番。PDFの「A問題（★問題）」「B問題（★問題）」
  「A問題」「B問題」の見出しが出るページで区切る。

## 踏んだ罠（同じ形が第3章以降にも出る）

### 図が選択肢そのもの
- ch01 は NO.10・15・19、ch02 は NO.25・34・43・**45**。
- **ch02 NO.45(105G-48) は選択肢a〜eが5枚のティンパノグラムの図だけで、本文に選択肢の文字が1つも無い。**
  PDF本文は設問文で終わっている＝テキストだけ見ていると「選択肢0個の問題」を作ってしまう。
  260〜280dpi に拡大して図を読み、各肢の文章を書き起こした。
- 拡大は `page.get_image_rects()` が返した矩形をそのまま `clip` に渡すのが確実
  （紙面の見た目で座標を当てると外す）。

### 図ラベル A/B の順序
`images` サブコマンドの出力は **x 座標を必ず見る**。
ch02 p.33（NO.44）は `B`(x=395) が `A`(x=194) より先に列挙された。読み順で決めると入れ替わる。

### 解答一覧表の行分割（2026-08-06 修正済み・再発しないが理由を知っておく）
国試番号が複数行に折り返し、**1行目がNO列のアンカーより上に来る**行がある
（NO.48 = `102A-42・` / `99A-11の` / `プール問題`、NO.199 = `113A-46・` 同型）。
`cmd_anstable` を「各単語を y が最も近いアンカーへ配る」方式へ直した。
**episode に `・` 区切りの複数コードが入る問題は、画像ファイル名を代表コード1つにする**
（`102A-42_1.jpeg`）。`pdf_audit.py` は `eid.split('・')` のどれかに一致すれば通す。
前方一致にしてはいけない（`112D-3` が `112D-63` を通る）。

### 線画の JPEG 品質
オージオグラム・ティンパノグラム・シェーマは **q85 だと格子線が崩れて `pdf_audit.py` が誤検出**する
（104D-1 実測 q85→hamming 7・q90→6・q95→0）。
`cmd_save` の `_is_line_art()` が**ほぼ無彩色の画像だけ q95** にする。触らないこと。
**`compress_images.py` は流さない**（既存2900枚超を再エンコードして巨大な差分を生む）。

### その他
- **PDF p.4 は「MECマイナー講座の特徴」の見本ページで、中身は精神科の問題。** ent として拾わない。
- 選択肢が**表**の問題に出くわしたら AI 抽出せず**その問題を保留にし、まとめてスクリーンショットを依頼**する
  （ガイド §1）。ch01・ch02 には無かったが、鼻・咽喉頭の章では組合せ問題が出る可能性がある。
- Bash の標準出力は cp932 で潰れる。生成した `.txt` は **Read ツールで読む**。

## 進め方の作法

- **1章ずつ「完成→ユーザー確認→次章」**。いきなり全章書かない。
- 解説はPDFに無くAIが執筆したものなので、**医学的正確性の抜き取り確認をユーザーに依頼する一文を必ず添える**。
  ch01・ch02 ぶんの確認はまだ未実施。
- `git commit --amend` は使わない（裏で別セッションが同じツリーを編集していることがある）。
  ステージは `git add -A` ではなくファイルを明示して行う。
- 章の push 直後は文脈の切れ目。**長くなっていたら新セッションを進言する。**
