## 2. 手順（第2章で実際に踏んだ順そのまま）

```
# ① 抽出（_work/_ph_tmp/ に出る。.gitignore 済み）
python _work/ph_pdf.py spec   --ch 3      # NO/国試番号/正解/バッジ/正答率
python _work/ph_pdf.py text   --ch 3      # 問題ページ本文（Readツールで読む）
python _work/ph_pdf.py images --ch 3      # 画像の帰属候補＋ページ画像（目視確認用）
python _work/ph_pdf.py text --ch 3 --resume --p0 18 --p1 25   # レジュメ（解説の正本）

# ② 生成器を分割して書く（1回のWriteに収まらないため）
#    _work/_ph_ch03_p1.py … pN.py（Q(...) を並べる）
#    _work/_ph_ch03_tail.py（_ph_ch02_tail.py をコピーし SECTIONS/章番号/章名だけ差し替え）
#    _work/_ph_join_ch03.py（_ph_join_ch02.py をコピーし ch02→ch03）
python _work/_ph_join_ch03.py && python _work/build_ph_ch03.py

# ③ JSON化 → 検証
python _work/build_ph_json.py
python _work/verify_ph_ch.py --ch 3        # 解答表との突合＋不変条件＋品質基準
python _work/pdf_audit.py ph --no-image    # PDF原文との中身照合

# ④ 統合（章を足すたびに必ず4か所）
#    gamify.js の ph の total ／ chapters_meta.js に ph_chNN ／
#    study.html の subj-hdr-count ／ sw.js の CACHE と SHELL_VERSION を bump
python _work/build_qmeta.py
node _work/test_subject_totals.js          # ここが落ちたら数の更新漏れ

# ⑤ 表示確認（file:// は不可）
python -m http.server 8765 --bind 127.0.0.1
#   → http://127.0.0.1:8765/study.html?sid=ph
```

⚠️ **`build_ph_chNN.py` を直接編集しない**（次の join で消える）。直すのはパート側。
⚠️ **拡張のタブは `document.hidden=true`** なので `content-visibility:auto` のカードが
スクリーンショットで白く写る。**確認は JS で DOM を読む**（getBoundingClientRect は正しく返る）。

## 3. この科目でハマる場所（`ph_pdf.py` に対処済み・触るときは壊さないこと）

1. **解答一覧表は10列で「疾患名」の列が無い**（精神科〜整形外科の版面と違う）。
2. **CBT列の ○ が出題テーマの1語目とくっついて1単語になる**（x≈173.7）。先頭の ○ を切り離す。
3. **「※不正解者のみ採点除外」の注記が2行に折り返し、2行目が次の行の国試番号セルへ流れ込む**
   （NO.15→NO.16、NO.33→NO.34 で実際に起きた）。国試番号は正規表現で取り直す。
4. **真の採点除外（解答＝なし・正答率－）は3問だけ**＝**NO.28・NO.111・NO.332**。
   この3問だけ `bx` バッジ・正解肢0・`rate=None`。
   **「※不正解者のみ採点除外」の4問（NO.15・33・272・616）は正解が存在＝通常扱い**。
   → **第3章には NO.111（111G-34・臓器提供意思表示カード）が入る**ので注意。
5. **マークシートの計算問題6問**（NO.207・218・238・245・259・263）は ch07・ch08。
   着手時に `calc_input.js` 方式（`計算答：<桁文字列>`）で作り、
   **`_work/test_calc_input.js` の「選択肢を持たない問題は計算問題50件」を56へ更新**する。
6. **右端に章名の縦書き**（x≈563-569）。`cmd_text` は x>545 を落としている。
7. **PDF p.6 は「MEC公衆衛生講座の特徴」の見本ページ**。問題ページ範囲 p7- で避ける。
8. **画像は実質30枚前後**（35ページに49枚だが p.2 目次サンプルと p.6 見本は設問外）。
   一方で**2×2表・人口ピラミッド・統計グラフが問題文に入る問題が多い**ので、
   そこは `<table class="tb">` で書き起こす（PDFを300dpiで描画して目視。スクショ依頼は不要）。
