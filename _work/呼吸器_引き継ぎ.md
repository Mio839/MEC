## ③ 画像の作り直し（2026-09-01 完了）

### 直した1: 並びの逆転 14問（31枚）

**`_1` が右の図・`_2` が左の図**になっていた（循環器で100問中21問だったのと同じ壊れ方）。
図ラベルは画像の外に組まれるので切り出した画像には写らず、**枚数チェックでは絶対に出ない**。

```
119C-36 115D-58 119D-17 115D-46 119A-37 119A-62 119D-32 115D-27
113A-29 113A-66 110A-34 116A-20 115A-22 111I-49
```

⚠️ **`111I-49` は「右乳房(A) / 左乳房(B) / 左乳房拡大(C)」で、狂うと左右を取り違える。**
⚠️ **直し方はファイルの中身を入れ替える**（`imgs` のリストは並べ替えない）。
   連番と図ラベルの対応が崩れると後から読めなくなる。
⚠️ **位置で並べ替えて済ませないこと**——`119A-62` は紙面が `B / A C` の順で、
   y座標だけで並べると必ず間違える。**矩形の直下のラベル語**が正本。
⚠️ ただしラベルが**図の上**に組まれる紙面がある（`119C-40` の ①〜⑤、`108E-49` の C①〜⑤）。
   A/B/C の版面は必ず下、丸数字の版面は上。`img_order.py` は下だけを見るので、
   丸数字の問題は NOLABEL で目視に落ちる（6問とも並びは正しかった）。
