🚨 常位胎盤早期剝離

常位胎盤早期剝離〈abruptio placentae〉：正常位置に付着した胎盤が児娩出前に子宮壁から剝離する病態。母児ともに致死的。

典型的な所見
・持続する（間欠のない）強い腹痛
・子宮の板状硬（子宮硬直）・圧痛
・性器出血（外出血は少ないことが多い＝血液は胎盤後血腫として子宮内に貯留）
・超音波で胎盤の肥厚像（＝胎盤後血腫）
・胎児心拍数陣痛図で基線細変動の減少・遅発一過性徐脈・徐脈（胎児機能不全）
・進行すればDIC（フィブリノゲン低下・FDP上昇・血小板減少）

危険因子：妊娠高血圧症候群・喫煙・外傷（腹部打撲）・絨毛膜羊膜炎・前期破水・子宮内胎児発育不全・既往

治療：診断がつき次第、母児救命のため直ちに帝王切開（＋DIC治療）。胎児死亡後で母体が安定していれば経腟分娩を選ぶこともある。

📊 本例の所見

・2時間前からの「痛みを伴う持続的な」子宮収縮 → 間欠のない疼痛
・血圧148/92mmHg → 妊娠高血圧症候群（早剝の最大の危険因子）
・少量の性器出血 → 外出血が少ないのが早剝の特徴
・胎盤の肥厚像 → 胎盤後血腫

これらを合わせて常位胎盤早期剝離と診断し、直ちに帝王切開を行う（母児救命のため一刻を争う）。

🩸 前置胎盤と癒着胎盤

前置胎盤：胎盤が内子宮口を覆う、または近接する。無痛性の反復する性器出血が特徴。内診は禁忌（大出血を招く）。分娩は帝王切開。

癒着胎盤〈placenta accreta spectrum〉：脱落膜（Nitabuch層）の欠損により絨毛が子宮筋層に直接侵入し、胎盤が自然に剝離しない。
　・accreta（癒着胎盤）：筋層表面に接着
　・increta（嵌入胎盤）：筋層内へ侵入
　・percreta（穿通胎盤）：筋層を貫通し漿膜・膀胱へ
分娩時に胎盤が剝がれず制御不能の大量出血 → 子宮全摘に至る。

危険因子（本例はすべて該当）：
　・帝王切開の既往（2回）
　・子宮内容除去術（掻爬）の既往
　・前置胎盤の合併（帝切既往＋前置胎盤で癒着胎盤の頻度が跳ね上がる）
　・高齢・多産・生殖補助医療

📸 胎児心拍数陣痛図の読み方

実際の記録は参照できないが、分娩第2期遷延（全開大から約3時間）の時点で遅発一過性徐脈や変動一過性徐脈の反復、基線細変動の減少といった胎児機能不全を示す所見が現れていると読む。この場合、速やかに児を娩出させる（急速遂娩）必要がある。

🔧 吸引分娩の適応と要件

適応：分娩第2期遷延・停止、胎児機能不全、母体疲労、母体合併症（心疾患等）でいきみを避けたい場合

要件（すべて満たすこと）
① 子宮口全開大　（本例：午後4時に全開大　✓）
② 破水している　（本例：午後6時50分に破水　✓）
③ 児頭が十分下降している（SP＋2cm以上、station ≧＋2）　（本例：SP＋4cm　✓）
④ 児頭骨盤不均衡〈CPD〉がない
⑤ 胎位・回旋が正常（児頭が先進部）
　（本例：0時方向に小泉門＝第1後頭位で正常な回旋（小泉門が恥骨側）　✓）
⑥ 膀胱を空にする

要件を満たさない、あるいは吸引3回で娩出できない場合は帝王切開へ移行する。

🩸 前置胎盤の管理

管理
・出血が少量で胎児が未熟 → 入院・安静・子宮収縮抑制薬で妊娠を延長
・大量出血・出血持続・母体循環動態の不安定・胎児機能不全 → 緊急帝王切開
・無症状なら妊娠37週前後の選択的帝王切開

本例は出血総量200mLで、なお子宮口から出血が持続しており、妊娠35週1日と児の成熟もある程度期待できる。これ以上待てば大量出血・母体ショックに至るため緊急帝王切開を選択する。

🔍 non-reactive NSTの解釈とBPS

NSTがnon-reactiveとなる原因には
・胎児の睡眠周期（sleep cycle）（正常でも20〜40分続く。最も多い）
・胎児の未熟性（妊娠32週未満では一過性頻脈が出にくい）
・母体の薬剤（鎮静薬・硫酸マグネシウム）
・胎児低酸素・アシドーシス（真の胎児機能不全）
があり、non-reactiveというだけでは偽陽性が非常に多い。

したがってBPS〈biophysical profile score〉で総合評価する。
5項目（各2点、計10点）：
　① NST（一過性頻脈）　② 胎児呼吸様運動　③ 胎動　④ 胎児筋緊張　⑤ 羊水量

　・8〜10点：胎児well-being良好 → 経過観察
　・6点：疑わしい → 24時間以内に再検
　・4点以下：胎児機能不全 → 分娩を考慮

BPSで超音波所見（呼吸様運動・胎動・筋緊張・羊水量）を加えることで、単なる睡眠周期による偽陽性を除外できる。

💓 遅発一過性徐脈〈late deceleration〉

波形：子宮収縮の開始より遅れて徐脈が始まり、収縮が終わってから緩やかに回復する（収縮のピークと徐脈の最下点がずれる）。

機序：子宮胎盤循環不全
　子宮が収縮すると、子宮筋層を貫くらせん動脈が圧迫されて絨毛間腔への血流が減少する。胎盤の予備能が十分なら胎児は影響を受けないが、予備能が低下していると収縮のたびに胎児が低酸素に陥り、化学受容器反射で徐脈を生じる。この反応に時間がかかるため徐脈が「遅れて」現れる。

原因
　・過強陣痛（収縮が強く長く頻回で、絨毛間腔の血流回復が間に合わない）
　・常位胎盤早期剝離（胎盤の有効面積が減少）
　・妊娠高血圧症候群・胎盤機能不全・FGR（もともと予備能が低い）
　・母体低血圧（仰臥位低血圧症候群・脊髄くも膜下麻酔）
　・母体の低酸素・重症貧血

🤰 仰臥位低血圧症候群〈supine hypotensive syndrome〉

妊娠後期の妊婦を仰臥位にすると、増大した子宮が下大静脈（脊柱のやや右側を走行）を圧迫する。
　→ 静脈還流の減少 → 心拍出量の低下 → 血圧低下
　→ 悪心・嘔吐・冷汗・顔面蒼白・意識消失、そして子宮胎盤血流の低下 → 胎児機能不全

脊髄くも膜下麻酔では交感神経が遮断されて血管が拡張しており、この機序による血圧低下がさらに増強される。

対応：子宮を左方へ移動させて下大静脈の圧迫を解除する
　・用手的に子宮を左側へ押しやる（手術中はこれが確実）
　・手術台を左に15〜30度傾ける、または右腰部に楔状のクッションを入れる
　・並行して輸液の急速投与、必要なら昇圧薬（エフェドリン・フェニレフリン）

📸 BTB試験紙

実際の写真は参照できないが、ブロモチモールブルー〈BTB〉試験紙である。

原理
　・腟内は酸性（pH 3.8〜4.5）（Döderlein桿菌が乳酸を産生）→ BTBは黄色
　・羊水は弱アルカリ性（pH 7.0〜8.5） → BTBが青変

したがって腟内容がアルカリ性を示せば破水（羊水の流出）と診断できる。

偽陽性に注意：血液・尿・精液・細菌性腟症の帯下・消毒薬もアルカリ性のため青変しうる。
より特異的な検査として羊歯状結晶〈ferning〉・IGFBP-1・癌胎児性フィブロネクチンがある。

これを圧受容器が感知して迷走神経反射により急激な徐脈（変動一過性徐脈）を生じる。

変動一過性徐脈の特徴
・急激に下降し急激に回復する（V字・W字・U字型）
・子宮収縮との時間的関係が一定しない
・軽度・散発的なら経過観察。高度・反復すれば体位変換・人工羊水注入・急速遂娩

💧 破水の分類と意義

破水の時期による分類
　・前期破水〈PROM〉：陣痛発来前の破水
　　　うち妊娠37週未満のものをpreterm PROM〈PPROM〉という
　・早期破水：陣痛発来後、子宮口全開大前の破水
　・適時破水：子宮口全開大のころの破水（生理的）
　・遅滞破水：全開大後も卵膜が破れない

破水の最大の問題は上行感染
　卵膜という物理的バリアが失われ、腟内細菌が子宮内へ侵入して絨毛膜羊膜炎〈CAM〉 → 母体敗血症、新生児敗血症・肺炎・髄膜炎、脳室周囲白質軟化症〈PVL〉・脳性麻痺を来す。破水から時間が経つほどリスクが高まる。
　このため破水後は内診の回数を最小限にし、体温・脈拍・白血球・CRP・CTGで感染を監視する。

長期の羊水過少が続けば肺低形成・四肢の関節拘縮（内反足）・臍帯圧迫も生じる。

📸 胎児心拍数陣痛図の読み方

実際の記録は参照できないが、正答から早発一過性徐脈〈early deceleration〉と読む。

早発一過性徐脈の特徴
・子宮収縮の開始と同時に徐脈が始まり、収縮のピークで最下点、収縮の終了とともに回復する
・子宮収縮曲線と心拍数曲線が鏡像（mirror image）をなす
・徐脈は緩やかで、心拍数の低下も軽度（多くは100bpm以上を保つ）
・基線細変動は保たれる

💓 機序：児頭圧迫 → 迷走神経反射

子宮収縮のたびに児頭が産道（骨盤・頸管）で圧迫される。
　→ 頭蓋内圧が一過性に上昇
　→ 迷走神経（副交感神経）が反射性に刺激される
　→ 心拍数が低下（徐脈）
　→ 収縮が終わり圧迫が解除されると心拍数は戻る

生理的な反射であり、胎児低酸素を意味しない。分娩第1期後半〜第2期（児頭が下降し産道を通過する時期）にしばしばみられる。処置は不要で、経過観察してよい。

🩸 癒着胎盤〈placenta accreta spectrum〉の危険因子

癒着胎盤は脱落膜（Nitabuch層）の欠損部に胎盤が付着し、絨毛が子宮筋層へ直接侵入する病態。

危険因子＝子宮内膜（脱落膜）が欠損・瘢痕化する状況
　・帝王切開の既往（最重要。1回で約3%、2回で約10%、3回以上で40%超）
　・子宮内容除去術・掻爬の既往（内膜の基底層が損傷）

💓 変動一過性徐脈〈variable deceleration〉

波形：急激に下降し急激に回復する（V字・W字・U字型）。子宮収縮との時間的関係が一定しない（variable）。

機序：臍帯圧迫
　① まず壁の薄い臍帯静脈が閉塞 → 胎児への還流が減少 → 一過性の心拍数上昇（shoulder）
　② 圧迫が強まると臍帯動脈も閉塞 → 胎児の末梢血管抵抗が急上昇 → 血圧上昇
　③ 圧受容器が感知し迷走神経反射で急激な徐脈
　④ 圧迫が解除されると急激に回復

臍帯圧迫を起こしやすい状況：羊水過少・破水後・臍帯巻絡・臍帯脱出・臍帯過長・分娩第2期の児頭下降

対応：軽度・散発的なら経過観察。高度・反復すれば体位変換（側臥位）・酸素投与・人工羊水注入、基線細変動の減少を伴えば急速遂娩。

所見波形原因意義
早発一過性徐脈子宮収縮と同時に始まり同時に回復（鏡像）児頭圧迫 → 迷走神経反射生理的

遷延一過性徐脈2分以上10分未満持続臍帯脱出・過強陣痛・母体低血圧危険
