□ 銀杏中毒——ビタミンB6の「偽物」がGABAを止める

銀杏はイチョウの種子で、食用になるのは胚乳の部分である。ここにMPN（4'-O-メチルピリドキシン）——ビタミンB6（ピリドキシン）のメチルエーテル——が大量に含まれる。

けいれんに至る道筋は一本道である。

  1. 本来、ビタミンB6の活性型（ピリドキサールリン酸〈PLP〉）はグルタミン酸脱炭酸酵素〈GAD〉の補酵素として、グルタミン酸 → γ-アミノ酪酸〈GABA〉の反応を進める。
  2. MPNはビタミンB6とよく似た構造をもつ拮抗物質で、活性型PLPが作られる段階を競合的に阻害する。
  3. 結果としてGADが働けず、興奮性のグルタミン酸が過剰・抑制性のGABAが不足となる。
  4. 脳のブレーキ（GABA）が外れてアクセル（グルタミン酸）だけが踏まれた状態＝けいれん。

MPNは耐熱性なので、加熱調理しても中毒は防げない。茶碗蒸しの銀杏も焼き銀杏も等しく危ない。

症状は摂取1時間〜半日後にけいれん・意識障害・消化器症状・呼吸困難。身体の小さい小児では5〜6粒でも発症し、特に3歳以下では重症になりやすい（本例は4歳）。

治療は①活性炭の投与 ②抗けいれん薬（ジアゼパム・ミダゾラム）③活性型ビタミンB6（ピリドキサール）の静脈注射——③が「拮抗物質を本物で押し返す」治療で、機序を知っていれば治療名まで導ける。

なお種子が熟すと外種皮が悪臭を放ち、素手で触れるとギンコール酸による接触皮膚炎を起こす。これはウルシと同系統のアレルゲンで、食中毒とは別の話である。

□ 選択肢の検討

選択肢解説
ａ　枝　豆枝豆による重篤な食中毒はまれ。生食すると消化不良で食中毒をきたすことはあるが、けいれんを起こす成分は含まれない。
◯ ｂ　銀　杏◯ 正解。選択肢の中でけいれんを起こしうるのはこれだけ。銀杏の胚乳に含まれるMPN（4'-O-メチルピリドキシン）がビタミンB6に拮抗し、GABAが作れなくなるためけいれんに至る。居酒屋＝茶碗蒸し・焼き銀杏という道筋も合う。
ｃ　マグロマグロによる重篤な食中毒はまれ。ただし鮮度の落ちた赤身魚を大量に食べると、ヒスチジンから細菌が作ったヒスタミンによる「アレルギー様食中毒」をきたすことがある。症状は顔面紅潮・蕁麻疹・頭痛でけいれんではない。しかも本例は皮疹を認めないと明記されている。
ｄ　焼き鳥焼き鳥による重篤な食中毒はまれ。ただし生焼けだとカンピロバクター食中毒をきたす。潜伏期は2〜5日で、2時間で発症する経過に合わない。
ｅ　ゆで卵ゆで卵による重篤な食中毒はまれ。ただし生茹でだとサルモネラ食中毒を起こす。潜伏期は6〜72時間で、やはり2時間には合わない。

□ なぜ57%まで割れたか——「けいれんの原因」を食材から選ばせる形の異様さ

本問が難しいのは、小児のけいれんという最頻の主訴に対して、鑑別ではなく「食材」を並べてくるためである。熱性けいれん・てんかん・低血糖・頭蓋内病変といった普段の道具立てが一切使えない。

そこで設問文が丁寧に潰していった可能性を数え直すのが正攻法になる。

  1. 体温36.5℃ → 熱性けいれんと感染症を消す。
  2. 過去に食事によるアレルギー歴はない・喘鳴なし・皮疹なし → アナフィラキシーを消す（＝マグロのヒスタミンも同時に消える）。
  3. 摂取から2時間 → カンピロバクター（2〜5日）もサルモネラ（6〜72時間）も間に合わない。

残るのは「食べたものそのものに、けいれんを起こす毒が入っていた」という筋だけで、選択肢5つのうちその条件を満たすのは銀杏ただ一つである。

なお心拍数170/分・呼吸数40/分・SpO2 91％は「けいれんが持続していること」の結果であって、原因を指す所見ではない。けいれん重積では筋の酸素消費と換気不全で必ずこうなる——ここに引きずられて呼吸器疾患を考えると迷路に入る。

成人でも大量（40粒以上とされる）に食べれば発症するが、国試に出るのはほぼ小児である。「小児＋けいれん＋直前に和食」で銀杏を思い出せるようにしておく。

□ 国試ポイント：銀杏中毒と自然毒の総論

  1. 銀杏の毒はMPN＝ビタミンB6拮抗物質。GABAが作れない → けいれん。治療は活性型ビタミンB6の静注。
  2. 小児は5〜6粒で発症、3歳以下は重症化。「子どもに銀杏を食べさせすぎない」は保健指導としても問われる。
  3. 自然毒はほぼすべて耐熱性——加熱調理の記載があっても自然毒は消えない。
  4. 摂取から発症までの時間が最強の分岐——数時間以内なら毒素型・自然毒、1日以上なら感染型。
  5. 関連する発展知識：ギンコール酸による接触皮膚炎、ヒスタミン（アレルギー様）食中毒、小児のけいれん重積の初期対応（気道確保・ジアゼパム静注）、イチョウ葉エキスと抗凝固薬の相互作用。

□ 「1時間」と「加熱済み」の2語で答えが決まる

本問は情報量の多い献立を丁寧に読ませておいて、実は2つの語だけで解けるという構造をしている。

第一の語は「午後9時に夕食、午後10時ころより腹痛」＝潜伏期およそ1時間。細菌が腸管で増えてから発症する感染型食中毒（サルモネラ・カンピロバクター・腸管出血性大腸菌）は、どれだけ早くても半日以上かかるので、この一段で d・e が消え、ウイルスの c も消える。残るのは「できあがった毒素を食べた」＝毒素型か自然毒だけである。

第二の語は「鍋物」「天ぷら」＝全食材が加熱されている。加熱で壊れない毒でなければならない。植物性自然毒はほとんどが耐熱性なので、これに適う。

この2つを通ると、献立の中で「検査も流通の網もくぐっていない食材」が昨日妻が自分で採った山菜ただ一つであることが浮かび上がる。牡蠣は冷凍、豆腐と野菜はスーパー、米飯と漬物は市販品——設問はわざわざ全品の出所を書いて、山菜だけを浮かせている。

□ 選択肢の検討

選択肢解説
ａ　アニサキスサバ・アジ・イワシ・スルメイカなどの海洋生物の生食で感染する。本例の献立に生食は無く、加熱処理で虫体は死ぬ。しかも発症までに数時間以上を要し、症状は激烈な心窩部痛で夫婦同時発症の下痢とは像が違う。
◯ ｂ　植物性自然毒◯ 正解。多くは耐熱性毒素なので、加熱調理済みという条件に矛盾しない唯一の選択肢。野生の山菜やキノコには食用に適さないものも多く、素人が安易に採取するとこのような事例に至る。
ｃ　ノロウィルス牡蠣は冷凍してあり、しかも鍋物で加熱処理しているので考えにくい。加えて潜伏期は12〜48時間で、1時間で発症する経過に合わない。
ｄ　カンピロバクター家畜の生焼けの肉で感染するが該当食品がない。しかも加熱処理は有効で、潜伏期は2〜5日。
ｅ　腸管出血性大腸菌家畜の生焼けの肉や糞尿に汚染された食物から感染するが加熱処理は有効。仮に妻が汚れた手で調理して糞口感染したとしても、潜伏期は3〜8日で当日の発症を説明できない。

□ 「夫は長期出張から帰ったばかり」——曝露をこの1食に閉じ込める一文

疫学の問題として読むと、この一文が共通曝露を「今日の夕食」だけに限定していることがわかる。夫は今日の午後8時まで家にいなかったのだから、夫婦が同じものを口にした機会は午後9時の食事しかない。家庭内の水・冷蔵庫の作り置き・数日前の食事といった可能性がすべて排除されるので、「同時に発症した2人の共通項」を探す作業が要らなくなる。

実務では、こういう症例で真っ先にすべきなのは「残った食品を捨てさせないこと」である。食中毒は診断がついたら保健所への届出（食品衛生法）が要り、原因究明には検体（残品・吐物・便）が要る。山菜の残りや天ぷらの残りがあれば、それが唯一の物証になる。

日本の自然毒による食中毒は、件数ではキノコ、死亡例では植物（イヌサフラン・トリカブト）が上位を占め、発生は「自分で採った」「知人にもらった」に集中する。スーパーで買ったものが原因になることは、まずない。

□ 国試ポイント：食中毒の絞り込み

  1. まず潜伏期を計算する——数時間以内＝毒素型・自然毒／半日＝ノロ・ウェルシュ／1日以上＝感染型。
  2. 加熱の有無で毒素型と感染型を分ける——毒素（黄色ブドウ球菌エンテロトキシン・自然毒）は耐熱性、菌そのものは加熱で死ぬ。
  3. 「自分で採った」「知人にもらった」は自然毒の合図。
  4. 食中毒（疑いを含む）を診断した医師は24時間以内に最寄りの保健所長へ届け出る（食品衛生法第63条）。感染症法ではなく食品衛生法であることに注意。

□ ジャガイモ中毒——同じ植物の中に食用部と有毒部がある

ジャガイモの有毒成分はステロイドグリコアルカロイドの一種であるα-ソラニン（およびα-チャコニン）である。

含まれる場所がはっきり決まっているのがこの中毒の特徴である。

  1. 芽（発芽部）——最も濃度が高い。
  2. 日光に当たって緑色になった皮の部分——クロロフィルは無毒だが、緑化と同時にソラニンも増えるため、「緑色」は毒の目印として使える。
  3. 未熟な小さいイモ——学校菜園で採れた小イモによる集団食中毒が毎年報告される。

機序は抗コリンエステラーゼ作用で、アセチルコリンが分解されずに溜まるため副交感神経刺激症状（ムスカリン様症状）——嘔吐・腹痛・下痢・徐脈——に加えて頭痛・めまいをきたす。有機リン中毒（第3章）と同じ機序だが、はるかに弱く通常は軽症で済む。

α-ソラニンは加熱で分解されないので、予防は「調理で壊す」ではなく「芽と緑色部を厚めに取り除く」「未熟なイモを食べない」「日光の当たらない冷暗所で保存する」という物理的な除去と保存の話になる。

ａ　たらの芽ウコギ科のタラノキの新芽で、天ぷらなどに調理される代表的な山菜である。「芽」という語につられやすいが無毒。
ｂ　青いトマトグリーントマトは未成熟のトマトで、ピクルスやサラダに利用できるほか、日に当てれば熟して赤いトマトになる。（微量のトマチンを含むが、通常の摂取量で中毒には至らない。）
ｃ　芽キャベツキャベツの変種で、ビタミンCを豊富に含み様々な食材として利用される。これも「芽」という語だけの引っかけ。
ｄ　発芽した大豆大豆の新芽はもやしとして食材になる（市販のもやしは大豆より緑豆を用いることが多い）。市販の良質な大豆も水に浸せば発芽する。
◯ ｅ　ジャガイモの新芽◯ 正解。α-ソラニンの抗コリンエステラーゼ作用により、嘔吐・腹痛・下痢・徐脈などのムスカリン様症状と頭痛を引き起こす。

□ 「食べられるものの中の食べられない部分」という出題の型

本問の4つの誤答は、「芽」「新芽」「発芽」「青い（未熟）」という同じ語感で並べてある。語感で選ぶと当たらず、「その植物に毒があるか」を知っているかだけが問われる。

同じ型の知識をまとめておく。いずれも「食材として流通しているのに、特定の部位・時期だけが毒」という構造である。

食材毒のある部分毒素と症状
ジャガイモ芽・緑色になった皮・未熟な小イモα-ソラニン。ムスカリン様症状・頭痛
銀杏胚乳そのもの（多食で）／外種皮は接触皮膚炎MPN。けいれん（→NO.22）

正答率97%の必修レベルの問題だが、「なぜ毒なのか」まで言えると NO.22・NO.23 も自動的に解ける——本章の3問はいずれも「加熱で壊れない毒が、食材の中に最初から入っていた」という同じ話をしている。

□ 国試ポイント：ジャガイモ中毒

  1. 毒素はα-ソラニン。芽・緑色の皮・未熟な小イモに多い。
  2. 抗コリンエステラーゼ作用 → ムスカリン様症状（嘔吐・腹痛・下痢・徐脈）＋頭痛。通常は軽症。
  3. 加熱では分解されない——予防は除去と冷暗所保存。
  4. 学校菜園の未熟なジャガイモによる集団食中毒は学校保健の題材としても出る。
  5. 関連する発展知識：有機リン中毒（同じ抗ChE作用・第3章）、ムスカリン様症状とニコチン様症状の区別、アミグダリンとシアン中毒（第6章）、乳児ボツリヌス症とハチミツ。
