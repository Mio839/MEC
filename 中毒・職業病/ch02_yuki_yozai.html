□ シンナーは「1つの物質」ではない——だからBMも複数が同時に上がる

シンナー thinner は塗料を薄めて粘度を下げるための溶剤の「混合物」であり、トルエン・キシレン・スチレンなどの芳香族炭化水素に、エステル・ケトン類が加わった複数成分からなる。単一物質ではないので、特殊健康診断でも複数の代謝産物が同時に高値を示す——ここが「2つ選べ」の根拠である。

本例の作業環境と作業管理を読み分けると、局所排気装置は稼働しているので作業環境（空気中濃度）に問題はなさそうである。ところが作業着が半袖で、手には軍手——有機溶剤は脂溶性が高く容易に経皮吸収されるので、軍手は有機化合物を自由に通し、半袖では前腕がそのまま曝露面になる。防毒マスクで気道は守れていても、皮膚から入っているという「作業管理の失敗」の典型である。

有機溶剤の性質そこから決まること
揮発性が高い容易に経気道吸収される → 局所排気装置と防毒マスクが要る
脂溶性が高い容易に経皮吸収される → 長そで・長ズボン＋（有機溶剤を通さない）手袋が要る。軍手は有機化合物を自由に通すので防護具にならない
脂溶性が高い（続き）血液-脳関門を通る → 中枢神経症状（頭痛・めまい・酩酊・依存）が出やすい
複数の溶剤に同時に曝露されるシンナーのような混合物ではBMの代謝物も複数が同時に上がる（→ NO.5）
有害業務の中で最多特殊健康診断の受診者数は有機溶剤が第1位
総論の一行——「有機溶剤は鼻からも皮膚からも入る」。毒性が高い物質（四アルキル鉛など）では防毒マスクだけでは無効で、作業環境管理（局所排気）と作業管理（保護衣）を組み合わせて初めて安全になる

□ BMの代謝物は「対応表」で覚える——名前だけで点になる

本問の正答率が49%と本章で最低なのは、「シンナー＝トルエン」と1対1で覚えていて、2つ目が出てこないためである。シンナーはトルエン・キシレン・スチレンの混合物と覚え直せば、選択肢の中で該当するのは馬尿酸とマンデル酸の2つと決まる。

また誤りの3肢は「BMではあるが対象が違う」（δ-ALA＝鉛）か、「そもそも特殊健診の項目でない」（アセトアルデヒド・コチニン）という2種類の外し方になっている。症例文の喫煙歴・飲酒歴は、まさに ｂ と ｄ を選ばせるために置かれた餌で、特殊健康診断は「その有害業務で曝露する物質」だけを測るという一線を引ければ引っかからない。

□ 国試ポイント：特殊健康診断と有機溶剤

  1. 特殊健康診断は有害業務に従事する労働者に雇入時・配置替え時・6か月以内ごとに1回。受診者数が最も多いのが有機溶剤で、有機溶剤中毒予防規則（有機則）が根拠。
  2. 有機溶剤の健康診断項目——問診、尿中蛋白、肝機能検査（AST・ALT・γ-GT）、物質ごとのBM（尿中代謝産物）。本例のAST 80・ALT 60という肝機能異常は、溶剤・飲酒のどちらでも説明できるので鑑別には使えない。
  3. 経皮吸収を止めるのは「保護衣と手袋」——軍手・布手袋は有機溶剤に対して無力で、溶剤に応じた耐透過性のある材質（ニトリル・フッ素ゴムなど）を選ぶ。作業衣の交換頻度も確認事項。
  4. 労働者数50人未満の事業場には産業医の選任義務がない（衛生推進者の選任にとどまる）。この種の小規模な塗装工場では、産業医が不在のことが多いという背景知識も本問の解説に添えられている。
  5. 関連する発展知識：有機溶剤の急性中毒（酩酊・頭痛・意識障害）、トルエン依存（シンナー遊び）、有機溶剤等健康診断結果報告書、局所排気装置の定期自主検査（1年以内ごと）。

□ 校正印刷工の胆管癌——記述疫学から規制が動いた実例

ジクロロプロパン C3H6Cl2はもともと粘膜刺激性物質として有機溶剤中毒予防規則（有機則）で規制されているだけの物質だった。ところが——

  1. 2012年5月、大阪市のオフセット校正印刷会社（労働者100人強、うち印刷工は約半数）で直近5人が胆管癌を発症し、うち4人が死亡していた事実が発覚した。発症年齢は25〜45歳と若く（60歳未満の胆管癌罹患率は10万対10程度）、作業との関連が強く示唆された。過去にさかのぼると17人が発症し9人が死亡していた。
  2. この時点でのエビデンスレベルは記述疫学にすぎなかったが、厚生労働省は全国の校正印刷工場を一斉調査し、他工場でも発症していること・主因がジクロロプロパンであることを確認、2013年3〜6月に労働災害として認定した。
  3. 同年、IARCがジクロロプロパンを「発がん性がある」グループ1に指定し、特化則の「特別管理物質」にも追加された。
  4. なお当該印刷会社は産業医選任義務を怠っており、罰金刑に処せられた。

この一連の流れは「職業がん」の教科書的な物語で、①若年発症 ②同一職場に集積 ③まれな癌という3点が揃ったら職業曝露を疑う、という診断のかたちを示している。

□ 選択肢の検討

選択肢解説
ａ　職場の分煙状況受動喫煙で肝胆道系疾患は生じない。受動喫煙が問題になるのは肺癌・虚血性心疾患・脳卒中・小児の喘息などである。
ｂ　最近5年間の健診受診の状況職場の定期健康診断の肝機能検査はALT・AST・γ-GTだが、初期の肝門部腫瘤では有意に上昇しない（胆道に浸潤すればALP・ビリルビンが上がるが、これらは定期健診の項目にない）。しかも肢は「受診の状況」であって「受診結果の内容」ではない——受けたか否かのイエス・ノーからは何も分からない。
ｃ　最近3か月の時間外勤務の状況過重労働で肝胆道系疾患は生じない。長時間労働が問題になるのは脳・心臓疾患（過労死）とメンタルヘルスである。
ｄ　作業時の防塵マスクの使用状況防塵マスクは粒子状物質を除くためのもので、印刷工程では粉塵に曝露されない。有害なガス・蒸気を防ぐには防毒マスクが要る（ジクロロプロパンを1％以上含む有機物質を局所排気装置のない環境で扱うときは有機ガス用防毒マスクの着用が求められる）。
◯ ｅ　過去に作業で使用した有機溶剤の種類◯ 正解。2012年に大阪市の校正印刷工場で若年労働者を含む胆管癌の多発が発覚し、疫学調査からジクロロプロパンが原因と推定され、2013年に特化則の「特別管理物質」（発がん関連物質）に指定された。印刷業の肝胆道系疾患をみたら、ジクロロプロパン取扱いの職業歴を確認する。

□ 「聞くべきこと」を選ぶ問題は、答えが変わる情報だけを残す

本問は「診断のために聴取すべきなのはどれか」という問い方で、誤りの4肢はいずれも「産業保健では大事だが、この患者の診断には結びつかない」もので構成されている。分煙＝呼吸器・循環器／過重労働＝脳心疾患とメンタル／防塵マスク＝粉塵（じん肺）と、それぞれ別の職業病の入口になっている点に注意する。

読み筋は「まれな癌＋若年＋特定の職種」。38歳で肝門部腫瘤（胆管癌）は明らかに若すぎ、喫煙も飲酒もない＝一般的なリスク因子で説明できない。残るのは職業歴だけで、しかも症例文は「20歳から印刷工場で印刷作業」と18年の曝露歴をわざわざ書いている。

□ 国試ポイント：職業がんと潜伏期

  1. 職業がんの3条件——①同一職場に集積 ②好発年齢より若い ③まれな組織型・部位。この3つが揃ったら疫学調査へ。
  2. 代表的な職業がん——ジクロロプロパン→胆管癌／芳香族アミン（β-ナフチルアミン・ベンジジン）→膀胱癌／石綿→肺癌・悪性胸膜中皮腫／ベンゼン→白血病／塩化ビニルモノマー→肝血管肉腫／クロム・ニッケル・ヒ素→肺癌／ITO→間質性肺炎〜肺癌。
  3. 潜伏期が長い（10〜40年）ので、特別管理物質は作業記録を30年間保存する義務がある。「過去に」使用した溶剤を聞くのはこのため。
  4. IARCの発がん性分類——グループ1＝ヒトに対して発がん性がある／2A＝おそらくある／2B＝可能性がある／3＝分類できない。ジクロロプロパン・ホルムアルデヒド・オルト-トルイジン・PFOAはグループ1。
  5. 関連する発展知識：労災認定（業務上疾病）、記述疫学 → 分析疫学（症例対照・コホート）という段階、産業医の選任義務（労働者50人以上）。

□ BMが高かったとき、産業医は何から手をつけるか

尿中馬尿酸はトルエンのBMである。吹付け（塗装）作業で馬尿酸を測っているということは、その職場でトルエン曝露が想定されているということにほかならない。そして結果は2.8g/L＝分布3、すなわち明らかな職業性曝露があるという判定である。

ここで産業医が最初にすべきことは「なぜ体内に入ったのか」を現場で確かめること、つまり職場巡視による作業状況の確認である。曝露を減らさない限り、次の健診でも同じ値が出る。

分布尿中馬尿酸意味産業医の対応
分布11g/L 以下職業性曝露はほぼ無い経過観察
分布21g/L 超 2.5g/L 以下曝露あり。境界域作業状況の確認と改善指導
分布32.5g/L 超明らかな職業性曝露職場巡視して作業状況を確認し、作業環境測定の管理区分が2・3なら事業者に環境改善を求める
我が国の有害業務の職場はほとんどが管理区分1（適切）——だから実際に問題になるのは「作業環境に問題がないのに、曝露濃度だけ高い」ケースで、原因は作業姿勢・防護具・休憩時の習慣にある。トルエンは空気より重いので床に溜まる——膝を床につけて塗装し、休憩時にその膝へ手を置いて喫煙する、といった場面を職場巡視で初めて目撃できる

□ 選択肢の検討

選択肢解説
◯ ａ　作業状況の確認◯ 正解。馬尿酸を測っている＝吹付け作業でトルエン曝露の危険があると推定でき、しかも結果は分布3（明らかな職業性曝露あり）である。まず職場巡視して作業状況を確認するのが産業医の役目。作業環境測定の管理区分が2（改善の余地あり）・3（不適切）なら事業者に環境改善を求める。

□ 生物濃縮——「脂に溶けて、壊れない」ものだけが食物連鎖を上る

生物濃縮 biomagnificationとは、環境中の物質が食物連鎖を通じて上位の生物ほど高濃度に蓄積していく現象である。これが起きるには物質の側に2つの条件が要る。

  1. 脂溶性が高い——脂肪組織に溜まり、尿から出ていかない。水溶性の物質は速やかに排泄されるので濃縮しない。
  2. 難分解性（生体内・環境中で壊れない）——代謝されずに残るから、食べるたびに足し算になる。

この2条件を満たす代表がメチル水銀・PCB・有機塩素系農薬（DDTなど）・ダイオキシン・PFOS/PFOAである。逆に塩化ビニルモノマーやテトラクロロエチレンのように分子量が小さく揮発性の高いものは濃縮しない——これらが起こすのは大気汚染・地下水汚染であって、魚の汚染ではない。

ｅ　テトラクロロエチレン常温で液体の物質で地下水汚染の原因にはなるが、分子量が小さく生物濃縮を起こさないので魚介類には蓄積しない（トリクロロエチレンも同じ）。

□ 「主要な」の一語が肢を1つに絞る

本問で最も紛らわしいのはｂ カドミウムである。カドミウムは確かに農畜水産物に蓄積し、魚介類からも摂取される。ところが設問は「主要な曝露源が魚介類摂取であるのはどれか」と書いており、日本人のカドミウム摂取は約半分が米、魚介類は10％程度にとどまる。「ありうる」と「主要な」は別である。

この読み方は他科でも効く——設問に付いた限定語（最も／まず／主要な／通常は／原則として）は、必ず肢を絞るために置かれている。限定語を読み落とすと、「間違ってはいない肢」が複数残って決められなくなる。

臨床への接続としては、妊婦の魚介類摂食指導が重要である。メチル水銀は胎盤を通過し、胎児の中枢神経発達に影響しうるため、厚生労働省はキンメダイ・メカジキ・クロマグロ・メバチマグロなど食物連鎖の上位にある魚は週1〜2回までという目安を示している。一方でツナ缶（キハダ・カツオ）、サケ、アジ、サバ、イワシ、サンマ、タイ、ブリなどは対象外——「魚を食べるな」ではなく「上位捕食者を控えめに」という指導になる。

□ 国試ポイント：生物濃縮と環境保健

  1. 生物濃縮の条件は「脂溶性＋難分解性」。分子量が小さく揮発性の高い有機溶剤は濃縮しない。
  2. 水俣病の初発症状は四肢のしびれ（末梢神経障害）で、進行するとHunter-Russell症候群（求心性視野狭窄・小脳性失調症・構音障害）。水俣病では難聴と感覚障害も高頻度。BMは毛髪中水銀（曝露が途絶えると速やかに低下する）。
  3. 胎児性水俣病——母体はほぼ無症状でも、胎盤を通過したメチル水銀により出生児に重度の中枢神経障害が生じる。胎盤は水銀を「濾す」のではなく「通す」。
  4. PFAS（PFOS・PFOA）は炭素とフッ素の強固な結合による撥水・撥油性で工業製品に広く使われ、高蓄積性・難分解性のため「永遠の化学物質」と呼ばれる。IARCはPFOAをグループ1、PFOSをグループ2Bに指定。
