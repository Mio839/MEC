□ サリンと化学テロ——「無色・無味・無臭で気付かない」

本連問は1995年3月の地下鉄サリン事件をモデルにした出題である。サリン（イソプロピルメタンフルオロホスホネート）は有機リン系化合物の一種で、無色・無味・無臭で揮発しやすいため、曝露されてもその瞬間には気付かない。加えて殺傷力が高く製造原価も安いため、化学兵器に適している。

症例文の「目の前が暗く感じ、鼻水が止まらない」という2つの訴えが、すでに縮瞳（→視野が暗い）と鼻汁＝ムスカリン様作用を示している。患者は徒歩で受診できているので曝露量はそれほど多くないが、その衣服には薬剤が付着したままである。

順序やること理由
①自分と施設の安全確保（個人防護具・ゾーニング）医療者が倒れたら、その後の全員が助からない
②脱衣と除染（脱衣だけで曝露の8〜9割が除去できる）汚染源を持ち込ませない・広げない。脱いだ衣類は密封できる袋に詰める
③通常のABC（気道・呼吸・循環）と全身管理ここでようやく普通の救急に戻る
④原因物質の同定（トキシドローム・SDS・現場情報）解毒薬の選択に必要
⑤解毒薬・拮抗薬有機リンならアトロピン＋PAM
通常の救急と順序が入れ替わるのは①②だけ——「バイタルを測る」「動脈血ガスを採る」は普段なら正しいが、除染前にやると医療者が曝露する。脱衣時は、服の汚染部分が患者の皮膚に触れないように指示する（Tシャツを普通に脱ぐと顔を通過して途中で意識を失いうる）

□ 選択肢の検討

選択肢解説
ａ　警察に問い合わせる。患者の救命が優先である。しかも大規模な化学テロの直後は警察も大混乱に陥っており、問い合わせても「調査中」という回答しか得られない。
ｂ　動脈血ガスを測定する。通常の救急であれば「最初に行うべき」作業だが、化学テロではこの作業をしているうちに医師に二次被害が生じる。患者救命の前の除染が鉄則。
ｃ　バイタルサインをチェックする。同上。ABCの評価すら除染より後になる。「普段は正しい」肢が、文脈が変わると誤りになるのがこの設問の核心。
ｄ　症状と発症時の状況とを詳しく聞く。問診している間に汚染された衣服から気化した薬剤に曝露し、医師も目の前が暗く感じ（縮瞳）、鼻水が止まらなくなるだろう。
◯ ｅ　患者に服を脱いでもらい、密封できる袋に詰めてもらう。◯ 正解。除染と、汚染の拡大阻止を同時に行う。脱衣だけで曝露の8〜9割が除去できるとされ、汚染源は密閉しなければならない。ただし脱ぐ際は、服の汚染部分が皮膚に触れないように指示する（Tシャツをいつも通りに脱ぐと、その途中で意識を失う可能性がある）。

□ 正答率26%——「普段の正しさ」が罠になる設問の型

本問は全48問中で最も正答率が低い（26%）。理由ははっきりしていて、ｂ 動脈血ガス・ｃ バイタルサインという「通常の救急なら間違いなく正しい」肢が並んでいるからである。実際、これらが誤りになるのは「化学テロ・化学災害」という文脈のときだけである。

読み替えの合図は症例文にすべて置かれている——①「液体のようなものがまかれた」②「レストラン内で数人が倒れた」③受付からの報告で「他の患者と接触のない一室に隔離するよう指示した」。③はすでに医師がゾーニングを始めていることを示し、「この症例は除染の物語である」と宣言しているのに等しい。

この構造は他の災害医療でも同じで、放射性物質の付着した患者（→第7章 NO.47）でも「まず脱衣と除染、医療者は防護、ゾーニング」という同じ順序が問われる。「自分の安全 → 汚染の遮断 → 患者の治療」という3段は、CBRNE災害に共通の背骨である。

□ 国試ポイント：CBRNE災害と除染

  1. CBRNE＝Chemical（化学）／Biological（生物）／Radiological（放射性物質）／Nuclear（核）／Explosive（爆発物）。いずれも「二次被害の防止」が最優先。
  2. ゾーニング——ホットゾーン（汚染区域）／ウォームゾーン（除染区域）／コールドゾーン（清潔区域）に分け、人と物の流れを一方向にする。
  3. 除染は「脱衣」が主役——脱衣だけで曝露の8〜9割が除去できる。その後に微温湯とシャワーによる水的除染。ただし金属ナトリウムなど水と反応する物質は乾式除染。
  4. サリン事件でのPAM——PAMは有機リン中毒の解毒薬という特殊な薬剤で、農業地帯近隣の病院以外には通常常備されていない。実際の事件でも全国から都心へかき集めて救命に寄与した。選択肢にPAMが無くてもアトロピンを選ぶのはこのため（→ NO.12）。
  5. 関連する発展知識：DMAT・災害拠点病院、START法によるトリアージ、個人防護具のレベル（A〜D）、神経剤（サリン・VX・ソマン）とびらん剤（マスタード）・窒息剤（ホスゲン）・血液剤（シアン）。

□ 症例文がすでに「有機リン」と言っている

患者は徒歩で医療機関を受診しており、曝露量はそれほど多くない。そのため意識は清明だが、縮瞳・対光反射消失・鼻汁・流涎・発汗というムスカリン様作用はすでに出そろっている。

一方四肢の運動麻痺はなく腱反射も正常なので、ニコチン様作用はまだ十分に出ていない。ただしSpO2 92％の低下と、それを代償する頻脈（108/分）・頻呼吸（24/分）は、気道分泌物の増加と呼吸筋収縮の弱まりが始まっていることを示唆する。呼吸筋麻痺こそが有機リン中毒の死因なので、ここは見逃せない所見である。

□ ChE低下は「有機リン」の指紋——ただし2種類ある

臨床で測るコリンエステラーゼには2種類ある。

別名存在部位特徴
真性ChEアセチルコリンエステラーゼ〈AChE〉、赤血球ChE神経終末・赤血球膜症状とよく相関するが、回復には赤血球の寿命（約120日）に沿った時間がかかる
偽性ChEブチリルコリンエステラーゼ〈BChE〉、血漿ChE肝で産生され血漿中に存在一般検査項目の「ChE」はこちら。感度が高く早く下がるが、肝障害・低栄養でも下がるので特異度は低い。回復は数日〜数週
ChEは肝の合成能を反映する項目でもある——ネフローゼ症候群・甲状腺機能亢進症・肥満では高値、肝硬変・低栄養・有機リン中毒では低値。「ChEが下がる」だけでは有機リンと決まらず、症状（縮瞳・発汗・分泌過多）と合わせて初めて決まる

なお有機リンによるリン酸化は時間が経つと"エイジング aging"して不可逆になる——PAMを早期に投与しなければならない理由がここにある。

□ 国試ポイント：ChEが下がる病態を並べる

  1. 有機リン中毒でChE低値——正答率98%の必修レベル。「農薬・殺虫剤・サリン」を見たらChE。
  2. ChE低値のその他の原因——肝硬変・劇症肝炎（肝の合成能低下）、低栄養、悪性腫瘍の末期。ChEはアルブミン・コレステロールと同じく「肝の合成能」の指標として並ぶ。
  3. ChE高値——ネフローゼ症候群、脂肪肝、糖尿病、甲状腺機能亢進症、肥満。
  4. 遷延性コリン作動性クリーゼと中間症候群——急性期を乗り切った1〜4日後に、呼吸筋・近位筋・脳神経支配筋の麻痺が再燃することがある（中間症候群）。症状が良くなっても人工呼吸の準備を解かない。さらに数週後に遅発性多発神経炎が起こりうる。
  5. 関連する発展知識：スキサメトニウム（脱分極性筋弛緩薬）は偽性ChEで分解されるので、ChE低下例・遺伝的ChE欠損例では遷延性無呼吸をきたす。有機リン曝露者に筋弛緩薬を使うときの落とし穴。

□ アトロピンとPAM——役割が違う2剤

有機リン中毒の薬物治療は2本立てで、それぞれ別の場所に効く。

薬作用効く症状効かない症状
アトロピンムスカリン受容体を競合的に遮断（対症療法）気道分泌物増加・気管支攣縮・徐脈・流涎・発汗・縮瞳・蠕動亢進ニコチン様作用（筋線維束攣縮・呼吸筋麻痺）には無効——受容体が違うため
PAM〈プラリドキシム〉リン酸化されたChEを脱リン酸化して酵素そのものを蘇らせる（原因治療）ニコチン様作用を含めた全症状エイジング後は無効＝早期投与が絶対条件。カーバメイト中毒にも無効
アトロピンの投与量の指標は「気道分泌物が乾くまで」——心拍数や瞳孔径ではなく、気道分泌が止まることを目標に大量・反復投与する（通常の用量では足りない）。加えて胃洗浄・活性炭投与・下剤投与、皮膚曝露なら脱衣と洗浄を並行して行う
機序症状治療
有機リン系農薬ChEをリン酸化して不可逆的に阻害（時間が経つと"エイジング"して戻らなくなる）Ach過剰（ムスカリン様＋ニコチン様＋中枢）アトロピン静注＋PAM（プラリドキシム）静注＋胃洗浄・活性炭・下剤
カーバメイトChEをカルバミル化——有機リンより結合しやすく、解離もしやすい同じくAch過剰だが発症は早く、軽症にとどまることが多いアトロピン（PAMは無効——もともと自然に外れるので脱リン酸化薬の出番がない）
ボツリヌス中毒（対照）Achの放出そのものを止める（副交感神経のアクセルが壊れた状態）抗ムスカリン様＋抗ニコチン様——散瞳・分泌不全（口渇）・排尿障害・弛緩性麻痺（下行性）。発熱せず意識も清明ボツリヌス抗毒素、呼吸管理
有機リンとボツリヌスは「Achが多すぎる／少なすぎる」で完全に鏡像——縮瞳と散瞳、分泌過多と分泌不全で見分ける。麻痺だけは両方に出るので、麻痺で分けようとすると間違える

□ 選択肢の検討

選択肢解説
◯ ａ　アトロピンの静脈内投与◯ 正解。有機リン中毒の治療はアトロピンとPAM（プラリドキシム）の静注。アトロピンは抗ムスカリン薬で、溢れたアセチルコリンからムスカリン受容体を守る（気道分泌物・徐脈・縮瞳に効く）。選択肢にPAMは無いが、PAMは有機リン中毒の解毒薬という特殊な薬剤で、農業地帯近隣の病院以外には通常常備されていない——実際の地下鉄サリン事件でも全国からかき集めた。
ｂ　ジアゼパムの筋肉内投与患者はけいれんを生じていないので不要。けいれんがあればベンゾジアゼピンは正しい治療になる（→ NO.13 の症例と対比）。
ｃ　アドレナリンの静脈内投与アナフィラキシー反応ではないので不要。皮疹・気道浮腫・血圧低下といったアナフィラキシーの所見はない。
ｄ　ネオスチグミンの内服投与ネオスチグミンはコリンエステラーゼ阻害薬＝コリン作動薬で、投与すれば病態は確実に悪化する。禁忌肢と考えてよい——火に油を注ぐ選択。
ｅ　亜硝酸ナトリウムの静脈内投与亜硝酸薬はシアン中毒の治療（メトヘモグロビンを作ってCN−を捕まえる）。本例はシアン中毒ではない。

□ 中毒でも順序はABC——ただし「酸素で上がらない」が決め手

中毒診療でも全身管理（ABC）が解毒より先である。本問が問うているのはそのABCの中でどこに手をつけるかで、気道（A）と呼吸（B）の両方が破綻しているので気管挿管になる。

「気管挿管を選ばせる」設問の合図は決まっている——

  1. 高濃度酸素を投与しているのにSpO2が上がらない（本問：リザーバ付マスク10L/分で85％）。酸素の量ではなく「換気」の問題だと分かる。
  2. 意識障害＋嘔吐（気道防御反射の消失）——誤嚥が必至。
  3. 舌根沈下や上気道閉塞があり、バッグバルブマスク換気でも改善しない（→ 第4章 NO.17 も同じ形）。
  4. 気道分泌物が多く反復吸引が要る（コリン作動性物質の特徴）。

逆に「全身冷却」「大量輸液」「中心静脈カテーテル」はいずれもその病態が存在しない——正しい治療でも、適応が無ければ誤りという基本の確認になっている。

ｃ　「ご家族に精神科通院中の方はいますか」精神疾患の一部には家族集積傾向があるが、「搬入直後」の治療には役に立たない。
ｄ　「お父さんはお酒をどれくらい飲みますか」大酒を飲んでその勢いで自殺したわけではないので無意味な質問である。（アルコールの併用は意識障害の増悪因子ではあるが、本例の縮瞳・発汗・けいれんを説明しない。）
ｅ　「お父さんはけいれんを起こしたことがありますか」過去のけいれんの有無で現在の治療法が変わるわけではない。てんかんの既往があったとしても、目の前の縮瞳・発汗・分泌過多は説明できない。

□ 「搬入直後の治療のために」という限定を効かせる

本問は選択肢のうち4つが「臨床的には意味があるが、今この瞬間の治療は変えない」もので構成されている。遺書・家族歴・飲酒歴・けいれんの既往は、いずれ聴取すべき情報ではある——特に遺書と精神科的背景は、救命後の自殺再企図の予防に不可欠だ。しかし設問はわざわざ「搬入直後の治療のために最も重要な」と時期と目的を二重に限定している。

これは第2章 NO.8（勤務先へ照会するもの）とまったく同じ判断基準——「その情報で、今の治療が変わるか」。変わらないなら、正しい情報でも「重要でない」。

臨床的には、原因物質を推定する材料は次の3つを組み合わせる。

  1. 現場の情報——容器・残薬・処方箋・空シート・臭い（→第4章 NO.18 では「室内に大量の薬の空シート」がこれに当たる）。
  2. トキシドローム——瞳孔・皮膚・分泌・腸蠕動・体温から毒物群を推定（→ NO.15）。
  3. 検査——尿の迅速簡易定性検査（トライエージ）、血中濃度測定、ChEなどの間接指標。

□ 選択肢の検討

選択肢解説
◯ ａ　コリン作動性◯ 正解。絶対的縮瞳・全身の著明な発汗・流涎と嘔吐・けいれんに、ChE 40U/L（基準240〜486）という著明な低下が加わってコリン作動性で確定する。ただし厳密には「コリン作動性薬中毒」までで、有機リンとカーバメイトなどの区別はここでは付かない（農業という生活歴が有機リンを強く示唆する）。
ｂ　交感神経興奮性アドレナリンなどの交感神経興奮性薬では散瞳し、粘膜の分泌や発汗も低下する（※発汗は増える型もあるが、本例の縮瞳・流涎とは合わない）。コカイン・アンフェタミンが代表。
ｃ　鎮静睡眠作用性鎮静睡眠薬では、けいれん・縮瞳・発汗はいずれも認められない。呼吸抑制・低血圧・低体温を伴う「静かな昏睡」になる。
ｄ　オピオイド作動性オピオイドは縮瞳をもたらす点は一致するが、けいれんや発汗は認められない。縮瞳をきたす2つのトキシドロームを分けるのは、発汗とけいれんの有無。
ｅ　ヒスタミン作用性H1受容体刺激ならアレルギー症状、H2受容体刺激なら胃酸分泌促進をもたらすが、けいれん・縮瞳・発汗は認められない。

□ 縮瞳する2つを分けるのは「発汗とけいれん」

本問で実質的に競合するのはａ コリン作動性とｄ オピオイド作動性の2つである——どちらも縮瞳をきたすからである。分けるのは発汗とけいれんで、オピオイドは「静かに呼吸が止まる」中毒であり発汗もけいれんも起こさない。

□ 国試ポイント：トキシドロームの使い方

  1. 見るのは瞳孔・皮膚（湿潤か乾燥か）・腸蠕動・体温の4点。この4つだけで5つのトキシドロームは判別できる。
  2. 縮瞳するのはコリン作動性とオピオイド、散瞳するのは抗コリン性と交感神経興奮性。散瞳する2つは「発汗の有無」で分ける——抗コリンは乾燥、交感神経興奮は湿潤（"dry as a bone"）。
  3. コリン作動性は有機リンだけではない——カーバメイト（殺虫剤）、ベサコリン・アセチルコリン塩化物（消化管機能亢進薬）、ネオスチグミン・ジスチグミン・ピリドスチグミン・アンベノニウム（重症筋無力症治療薬）。厳密には現時点で確定できるのは「コリン作動性薬中毒」まで。
  4. ChEは基準240〜486に対して40＝10分の1以下で、重症のコリンエステラーゼ阻害を示す。
  5. 関連する発展知識：セロトニン症候群（発熱・自律神経症状・腱反射亢進とクローヌス）と悪性症候群（発熱・鉛管様筋強剛・CK上昇）——薬剤性の症候群としてトキシドロームと並べて整理する。
